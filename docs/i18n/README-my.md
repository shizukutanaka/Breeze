**ဖုန်းနံပါတ်လည်း မှတ်ပုံတင်ခြင်းလည်း မလိုအပ်သော ကုဒ်ဝှက်ထားသည့် စာတိုပေးပို့ရေးအက်ပ် ဖြစ်ပါသည်။**
စကားဝိုင်း၏ အကြောင်းအရာကို ပို့သူနှင့် လက်ခံသူသာ ဖတ်နိုင်ပါသည်။ လမ်းတစ်လျှောက် သယ်ဆောင်ပေးသည့် ဆာဗာပင် မဖတ်နိုင်ပါ။
လုပ်ဆောင်ချက်အားလုံး အခမဲ့ဖြစ်ပြီး ကြော်ငြာလည်း မရှိပါ။

၎င်းသည် ဝဘ်စာမျက်နှာ မဟုတ်ဘဲ ထည့်သွင်းအသုံးပြုရသည့် ဆော့ဖ်ဝဲ ဖြစ်ပါသည် (Windows / Mac / Linux / Android / iPhone / ဘရောက်ဇာ)။

## အသုံးပြုရန် ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ရပါမည်

Breeze တွင် "လည်ပတ်သည့်ကုမ္ပဏီ၏ ဆာဗာ" မရှိပါ။ **အသုံးပြုရန် သင်ကိုယ်တိုင် နေရာ (ဆာဗာ) တစ်ခုကို ပြင်ဆင်ပြီး Breeze ကို ထိုနေရာတွင် တင်ရပါမည်။ ဤသည်မှာ တရားဝင် အသုံးပြုနည်း ဖြစ်ပါသည်။**

- အခမဲ့နေရာ ဆိုလျှင် လုံလောက်ပါသည်။ Cloudflare ၏ အခမဲ့အဆင့်အတွင်း လည်ပတ်နိုင်ပြီး ခရက်ဒစ်ကတ် မလိုအပ်ပါ။ အဆင့်ဆင့်ကို [တပ်ဆင်ခြင်းလမ်းညွှန်](SELF_HOSTING-my.md) တွင် ဖော်ပြထားပါသည် (အခြားဘာသာစကားများကို လမ်းညွှန်၏ အစပိုင်းမှ ရွေးချယ်နိုင်ပါသည်)။
- အက်ပ်များ (Windows / Mac / Linux / Android / iPhone) ကို [ဒေါင်းလုဒ်စာမျက်နှာ](https://github.com/shizukutanaka/Breeze/releases/latest) မှ ရယူပြီး ကိုယ်ပိုင်ဆာဗာနှင့် ချိတ်ဆက်၍ အသုံးပြုရပါသည်။
- **နမူနာတပ်ဆင်မှုအကြောင်း (ရိုးသားစွာ အသိပေးချက်)**: လည်ပတ်မှုစစ်ဆေးရန် နမူနာတစ်ခု (https://breeze-469.pages.dev/) ကို တင်ထားပါသည်။ တင်ထားသည့် ဆော့ဖ်ဝဲမှာ အတူတူပင် ဖြစ်သော်လည်း လက်တွေ့အသုံးပြုမှုအတွက် ကိုယ်ပိုင်ဆာဗာကို အသုံးပြုပေးပါ။ နမူနာသည် အသိပေးခြင်းမရှိဘဲ ပြောင်းလဲနိုင်သည် သို့မဟုတ် ရပ်တန့်နိုင်ပါသည်။ ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသောအရာများသည် နမူနာ ရပ်တန့်ခြင်း၏ သက်ရောက်မှုကို မခံရပါ။

အသေးစိတ် အသုံးပြုနည်းကို [လက်စွဲစာအုပ်](MANUAL-my.md) တွင် ဖော်ပြထားပါသည် (အခြားဘာသာစကားများကို လက်စွဲစာအုပ်၏ အစပိုင်းမှ ရွေးချယ်နိုင်ပါသည်)။

## အသုံးပြုနည်း (အဆင့် ၃ ဆင့်)

1. ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသည့် Breeze (သို့မဟုတ် တင်ထားသူမှ ပြောပြသည့် လိပ်စာ) ကို ဖွင့်ပြီး သင့်အမည်ကို ထည့်ပါ။ ထိုမျှဖြင့် ပြင်ဆင်မှု ပြီးဆုံးပါသည် (မှတ်ပုံတင်ခြင်းလည်း ဖုန်းနံပါတ်လည်း မလိုအပ်ပါ)။ ထိုအချိန်တွင် စက်ပစ္စည်းအတွင်း၌ "သော့" တစ်ခု ဖန်တီးပြီး ထိုသော့သည် သင်၏ အမှတ်အသား ဖြစ်လာပါသည်။
2. စကားပြောလိုသူကို သင်၏ ID သို့မဟုတ် QR ကုဒ်ကို ပေးပါ။
3. တစ်ဖက်လူလည်း အက်ပ်ကို ဖွင့်ထားပါက တိုက်ရိုက်ချိတ်ဆက်၍ စကားပြောနိုင်ပါသည်။ မဖွင့်ထားပါက စာကို ကုဒ်ဝှက်ထားသည့် အခြေအနေဖြင့် "သိမ်းဆည်းပုံး" တွင် ထားပြီး တစ်ဖက်လူ ဖွင့်သည့်အခါ ပို့ပေးပါသည်။ သိမ်းဆည်းပုံးကို သယ်ဆောင်သည့် ဆာဗာသည် အကြောင်းအရာကို မဖတ်နိုင်ပါ။ မပို့နိုင်ဘဲ ကျန်နေသည့် စာများသည် အများဆုံး ၇ ရက်အတွင်း အလိုအလျောက် ပျက်သွားပါသည်။

## ကတိကဝတ်များ (မလုပ်မည့်အရာများ)

- **ကြော်ငြာ မပြပါ။** အက်ပ်အတွင်းမှာရော မည်သည့်နေရာမှာမှ မပြပါ။
- **ခြေရာခံ မလုပ်ပါ။** အသုံးပြုမှု ခွဲခြမ်းစိတ်ဖြာခြင်း၊ ကြော်ငြာစနစ်များ၊ ဒေတာ ရောင်းချခြင်း လုံးဝ မလုပ်ပါ။
- **ဖန်တီးသူသည် အသုံးပြုသူများ၏ ဒေတာကို မကိုင်ဆောင်ပါ။** ဆာဗာဘက်တွင် အကောင့်စာရင်း ကိုယ်နှိုက်ပင် မရှိပါ။ သင်၏ အမှတ်အသားမှာ သင့်စက်ပစ္စည်းအတွင်းရှိ သော့တစ်ခုသာ ဖြစ်ပါသည်။
- **စကားဝိုင်းများကို စက်ပစ္စည်းအချင်းချင်းကြား ကုဒ်ဝှက်ပါသည်။** ဆာဗာက ကိုင်တွယ်သည်မှာ မဖတ်နိုင်သည့် စာအိတ်များသာ ဖြစ်ပါသည်။

နယ်ပယ်ကိုလည်း ရိုးသားစွာ ရေးသားထားပါသည်။ ပို့ဆောင်ရန်အတွက် ဆာဗာသည် အချို့အရာများကို ခေတ္တသိမ်းဆည်းထားပါသည် (မပို့ရသေးသည့် စာအိတ်များ အများဆုံး ၇ ရက်၊ ချိတ်ဆက်မှု အချက်ပြမှုများ ၅ မိနစ်၊ လိပ်စာနှင့် စက်ပစ္စည်း မှတ်တမ်းများ ရက် ၉၀၊ အုပ်စုအချက်အလက်နှင့် အကြောင်းကြားချက် စာရင်းသွင်းမှုများ ရက် ၃၀။ အားလုံး အလိုအလျောက် ပျက်သွားပြီး အကြောင်းအရာကို မဖတ်နိုင်ပါ)။ တိမ်တိုက်သို့ အရန်သိမ်းဆည်းခြင်းသည် အစတွင် ပိတ်ထားပါသည်။ ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ပါက ထိုသိမ်းဆည်းမှုသည်လည်း သင့်ကိုယ်ပိုင် စီမံခန့်ခွဲမှုအောက်တွင် ရှိပါမည်။

## ရာဇဝတ်မှုအတွက် အသုံးပြုလျှင် မတန်အောင် ဒီဇိုင်းဆွဲထားပါသည်

Breeze ကို အလွဲသုံးစားပြုသူ ဘက်က ကုန်ကျစရိတ်နှင့် လုပ်အားထည့်ရအောင် ပြုလုပ်ထားပါသည်။ "ရာဇဝတ်မှုကို မဖြစ်နိုင်အောင် လုပ်သည်" ဟု မပြောပါ။ "မတန်အောင် လုပ်သည့်" ဒီဇိုင်း ဖြစ်ပါသည်။

- **အခမဲ့ ကပ်ပါးအသုံးပြုရန် အခြေခံ မရှိပါ။** ဗဟို အခမဲ့ဆာဗာ မရှိသည့်အတွက် အလွဲသုံးစားပြုလိုသူသည်လည်း ကိုယ်ပိုင်အမည်ဖြင့် အကောင့်နှင့် ကိုယ်ပိုင်ကုန်ကျစရိတ်ဖြင့် နေရာတစ်ခု ပြင်ဆင်ရမည့် အခြေအနေသာ ရှိပါသည်။
- **ပို့ဆောင်ခြင်းတွင် ဝန်ထုပ်ဝန်ပိုး ရှိပါသည်။** ပို့တိုင်း တွက်ချက်မှုအသေးစား (အလုပ်လုပ်ခဲ့ကြောင်း သက်သေ) ကို တောင်းဆိုပြီး ပမာဏ အကန့်အသတ်လည်း သတ်မှတ်ထားပါသည်။ အမြောက်အမြား စပမ်းပို့ခြင်းသည် မတန်ပါ။
- **ငြင်းမရသည့် တိုင်ကြားမှု ပြုလုပ်နိုင်ပါသည်။** လက်ခံသူသည် လက်ခံရရှိသည့် ပို့ဆောင်မှုကိုယ်နှိုက်ကို သက်သေအဖြစ် တိုင်ကြားနိုင်ပါသည်။ ပို့သူဘက်က "ငါ မပို့ခဲ့ဘူး" ဟု ငြင်းမရပါ။
- **ရပ်တန့်ရန် အခွင့်အာဏာမှာ တင်ထားသူ၌ ရှိပါသည်။** ကိုယ်ပိုင်ဆာဗာပေါ်တွင် ဖြစ်ပျက်သည့်အရာများကို သင်ကိုယ်တိုင် ရပ်တန့်နိုင်ပါသည်။ မည်သူ့ ခွင့်ပြုချက်မှ မလိုအပ်ပါ။

## လုပ်ဆောင်နိုင်သည့်အရာများ

- တစ်ဦးချင်း စကားဝိုင်းနှင့် အုပ်စု စကားဝိုင်း (အများဆုံး လူ ၁,၀၀၀)
- အသံခေါ်ဆိုမှုနှင့် ဗီဒီယိုခေါ်ဆိုမှု
- ဖိုင်ပို့ခြင်း (တစ်ဦးချင်းတွင် အများဆုံး 50MB။ အုပ်စုတွင်လည်း ပို့နိုင်သော်လည်း အရွယ်အစား အကန့်အသတ်မှာ ပိုသေးပါသည်)
- စက်ပစ္စည်းများစွာနှင့် အကောင့်များစွာ အသုံးပြုခြင်း (အလုပ်သုံးနှင့် ကိုယ်ရေးကိုယ်တာသုံး စသဖြင့်။ စက်ပစ္စည်း အရေအတွက်ရော အကောင့် အရေအတွက်ပါ အခမဲ့နှင့် အကန့်အသတ်မရှိပါ)
- ဘာသာစကား ၈ မျိုး (အင်္ဂလိပ်၊ ဂျပန်၊ ကိုရီးယား၊ တရုတ် (ထိုင်ဝမ်)၊ စပိန်၊ ထိုင်း၊ အင်ဒိုနီးရှား၊ ပေါ်တူဂီ) မှ အလိုအလျောက် ရွေးချယ်ပေးပါသည်
- ဓာတ်ပုံပါသည့် ပရိုဖိုင်၊ စတစ်ကာများ၊ တည်နေရာ မျှဝေခြင်း
- `/help` ကဲ့သို့သော အမိန့်ပေး လုပ်ဆောင်မှုများ (အမျိုးအစား ၆၀ ကျော်)

## အခြား စာတိုပေးပို့ရေးအက်ပ်များနှင့် ကွာခြားချက်

| | Breeze | စာတိုပေးပို့ရေးအက်ပ် အများစု |
|---|--------|--------|
| မှတ်ပုံတင်ခြင်း | မလိုအပ်ပါ (အမှတ်အသားမှာ စက်ပစ္စည်းအတွင်းရှိ သော့ ဖြစ်ပါသည်) | ဖုန်းနံပါတ် လိုအပ်ပါသည် |
| ဆာဗာ | အကြောင်းအရာကို မဖတ်နိုင်ပါ | လည်ပတ်သည့်ကုမ္ပဏီကို ယုံကြည်မှုအပေါ် အခြေခံပါသည် |
| ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ခြင်း | အခြေခံအခြေအနေ (တင်၍ အသုံးပြုရသည့်အရာ) | မလုပ်နိုင်ပါ |
| အတွင်းပိုင်း ထုတ်ဖော်ခြင်း | အားလုံး ထုတ်ဖော်ထားပါသည် (MIT လိုင်စင်) | မထုတ်ဖော်သည်က များပါသည် |
| ဒေတာ တည်နေရာ | သင့်စက်ပစ္စည်းအတွင်း | လည်ပတ်သည့်ကုမ္ပဏီ၏ ဆာဗာပေါ် |

Signal နှင့် LINE တို့နှင့် အသေးစိတ် နှိုင်းယှဉ်ချက်ကို [နှိုင်းယှဉ်ချက် စာမျက်နှာ (အင်္ဂလိပ်)](../COMPARISON.md) တွင် ဖော်ပြထားပါသည်။ Breeze ၏ အဆိုပြုချက်တစ်ခုချင်းစီတွင် "စစ်ဆေးရန် နည်းလမ်း" ပါရှိပြီး Breeze ရှုံးနိမ့်နေသည့် အချက်များ (အသုံးပြုသူ အရေအတွက်၊ ပြင်ပ စစ်ဆေးမှု မခံရသေးခြင်း စသည်) ကိုလည်း ဖုံးကွယ်မထားဘဲ ရေးသားထားပါသည်။

## ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်သည့်အခါ ကုန်ကျစရိတ်

Breeze သည် Cloudflare ၏ အခမဲ့အတိုင်းအတာအတွင်း လည်ပတ်ပါသည်။ ခရက်ဒစ်ကတ် မလိုအပ်ပါ။

| အရာ | အခမဲ့ အတိုင်းအတာ | ငွေပေးရသည့်အခါ |
|-----------|-----------|-------------|
| နေရာ | Cloudflare Pages (အခမဲ့) | — |
| စီမံဆောင်ရွက်ခြင်း | တစ်နေ့လျှင် အကြိမ် ၁၀၀,၀၀၀ အထိ | တစ်လလျှင် အကြိမ် ၁၀ သန်း အထိ |
| သိမ်းဆည်းခြင်း | တစ်နေ့လျှင် ဖတ်ခြင်း အကြိမ် ၁၀၀,၀၀၀ အထိ၊ ရေးခြင်း အကြိမ် ၁,၀၀၀ အထိ | တစ်လလျှင် ဖတ်ခြင်း အကြိမ် ၁၀ သန်း၊ ရေးခြင်း အကြိမ် ၁ သန်း |
| ခေါ်ဆိုမှု အစားထိုးပို့ဆောင်ခြင်း | 20GB အထိ အခမဲ့ | 1GB လျှင် ၀.၀၅ ဒေါ်လာ |
| ကိုယ်ပိုင် ဒိုမိန်း | မလိုအပ်ပါ (အခမဲ့ လိပ်စာ ပါရှိပါသည်) | တစ်နှစ်လျှင် ၁၀ ဒေါ်လာ |
| **စုစုပေါင်း** | **တစ်လလျှင် ၀ ဒေါ်လာ** (ပေါ့ပေါ့ပါးပါး အသုံးပြုမှုဖြင့် လူ ၂၀–၄၀ ခန့်အထိ) | **တစ်လလျှင် ၅ ဒေါ်လာမှ စတင်ပါသည်** (ပေါ့ပေါ့ပါးပါး အသုံးပြုမှုဖြင့် လူ ၁၀၀ ခန့် အတိုင်းအတာ။ လူ ၁,၀၀၀ အတိုင်းအတာတွင် အသုံးပြုမှုပေါ် မူတည်၍ တစ်လလျှင် ၃၄–၂၂၂ ဒေါ်လာ) |

ကြီးမားသော အတိုင်းအတာတွင် ကုန်ကျစရိတ် ကြီးထွားလာပုံနှင့် "လည်ပတ်သူ တစ်ဦးတည်းက အားလုံး၏ ကုန်ကျစရိတ်ကို ဘာကြောင့် ထမ်းစရာ မလိုသနည်း" ဆိုသည်ကို [ကုန်ကျစရိတ်နှင့် တည်တံ့မှုဆိုင်ရာ အတွေးအခေါ် (အင်္ဂလိပ်)](../SUSTAINABILITY.md) တွင် ဖော်ပြထားပြီး အခြေခံ တွက်ချက်မှုများကို [ကုန်ကျစရိတ် ပုံစံ (အင်္ဂလိပ်)](../COST_MODEL.md) တွင် ဖော်ပြထားပါသည်။

တပ်ဆင်ခြင်းသည် ဤအမိန့်တစ်ခုမှ စတင်ပါသည် (အသေးစိတ်ကို [တပ်ဆင်ခြင်းလမ်းညွှန်](SELF_HOSTING-my.md) တွင် ကြည့်ပါ)။

```bash
wrangler pages deploy . --project-name=breeze
```

## နည်းပညာ အသေးစိတ်များ (ဆော့ဖ်ဝဲရေးသူများအတွက်)

### ကုဒ်ဝှက်နည်း

| အခန်းကဏ္ဍ | နည်း |
|-------|-----------|
| သော့ လဲလှယ်ခြင်း | X25519 (အရန်: P-256) |
| လက်မှတ် | Ed25519 (အရန်: HMAC-SHA256) |
| ကုဒ်ဝှက်ခြင်း | AES-256-GCM |
| သော့ ဆင်းသက်စေခြင်း | HKDF-SHA256 |
| စကားဝိုင်း သော့ အပ်ဒိတ်လုပ်ခြင်း | Double Ratchet (Signal နှင့် တူညီသောနည်း) |
| အုပ်စု သော့ | Sender Key |
| ပို့သူကို အစားထိုးပို့ဆောင်သူမှ ဖုံးကွယ်ခြင်း | Sealed Sender |

ဒီဇိုင်း၏ အဓိကစာရွက်စာတမ်းမှာ [သတ်မှတ်ချက် စာရွက်စာတမ်း SPEC.md](../../SPEC.md) ဖြစ်ပြီး အားနည်းချက် တိုင်ကြားရန်နေရာနှင့် မူဝါဒကို [SECURITY.md](../../SECURITY.md) တွင် ဖော်ပြထားပါသည်။

### စမ်းသပ်မှုများနှင့် အရည်အသွေး စစ်ဆေးမှုများ

npm ci            # 開発用の道具を入れる

## English

Breeze is an end-to-end encrypted messenger with no phone number, no registration, and no ads — every feature is free. There is no company server: to use Breeze, you host it on your own server (Cloudflare's free tier is enough) and connect the apps to it. Your identity is a key pair on your device; relays handle only sealed envelopes they cannot read. Full text in English: [README-en.md](README-en.md). The full, sourced comparison against Signal and LINE — including where Breeze loses — is in [../COMPARISON.md](../COMPARISON.md).
