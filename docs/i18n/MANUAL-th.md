# คู่มือการใช้งาน Breeze

Breeze เป็นแอปส่งข้อความที่เข้ารหัส ไม่ต้องใช้เบอร์โทรศัพท์ ไม่ต้องลงทะเบียน
เนื้อหาของการสนทนาอ่านได้เฉพาะผู้ส่งและผู้รับเท่านั้น แม้แต่เซิร์ฟเวอร์ที่ขนส่งอยู่ระหว่างทางก็อ่านไม่ได้
ทุกฟังก์ชันใช้งานฟรี และไม่มีโฆษณา

คู่มือนี้เป็นแนวทางสำหรับผู้ที่เริ่มใช้งาน

---

## 1. วิธีเริ่มต้น

### การรับแอป

จาก [หน้าดาวน์โหลด](https://github.com/shizukutanaka/Breeze/releases/latest) โปรดเลือกไฟล์ที่เหมาะกับเครื่องของคุณหนึ่งไฟล์

- Windows: ไฟล์ที่ชื่อลงท้ายด้วย `-win-x64.exe` (มีสำหรับเครื่อง ARM ด้วย)
- Mac: ไฟล์ที่ชื่อลงท้ายด้วย `-mac.dmg`
- Linux: `.AppImage` (เรียกใช้ได้ทันที) หรือ `.deb`
- หากใช้ในเบราว์เซอร์ ให้ใช้ตัวที่ติดตั้งบนเซิร์ฟเวอร์ของตัวเอง (ขั้นตอนการติดตั้งอยู่ในเอกสารแยก "คู่มือการติดตั้ง") การติดตั้งแบบมาตรฐานใช้ Cloudflare ดังนั้นจำเป็นต้องมีบัญชี Cloudflare

แต่ละไฟล์มีค่าตรวจสอบ (SHA256SUMS.txt) แนบมาด้วย หากกังวล สามารถตรวจสอบได้ว่าค่าของไฟล์ที่ดาวน์โหลดมาตรงกันหรือไม่

### การตั้งค่าครั้งแรก

1. เปิดแอป
2. กด "เริ่มต้นด้วย ID สุ่ม" เพียงเท่านี้ก็พร้อมใช้งาน ไม่ต้องลงทะเบียน ไม่ต้องใช้เบอร์โทรศัพท์

- หากใส่ "ชื่อของคุณ (ชื่อที่แสดง)" ในช่องเหนือปุ่ม คุณจะเริ่มต้นด้วยชื่อนั้น คุณยังสามารถกดปุ่มโดยปล่อยช่องว่างไว้ได้เช่นกัน คุณสามารถเปลี่ยนชื่อที่แสดงได้ภายหลังในส่วนโปรไฟล์ของการตั้งค่า
- ยังมีวิธีสร้างตัวตนด้วยชื่อและ Breeze ID ที่คุณเลือกเองด้วย ในกรณีนั้น วลีสำหรับกู้คืนจะถูกออกและแสดงบนหน้าจอ วลีสำหรับกู้คืนคือคำที่ช่วยให้คุณนำตัวตนนั้นกลับมาบนอุปกรณ์อื่นได้ โปรดจดไว้บนกระดาษหรือในที่ปลอดภัย
- หากต้องการนำตัวตนที่เคยสร้างไว้กลับมา ให้เปิด "กู้คืนบัญชีที่มีอยู่" แล้ววิธีการกู้คืน (กู้คืนจากไฟล์สำรองข้อมูล กู้คืนด้วยวลีสำหรับกู้คืน กู้คืนด้วยบัญชี + วลีรหัสผ่าน) จะปรากฏ
- เมื่อสร้างเสร็จ จะมีบัตรปรากฏขึ้นเพื่อแนะนำให้ป้องกันกุญแจด้วยวลีรหัสผ่าน (บัตรจะไม่หายไปเมื่อเวลาผ่านไป) สำหรับตัวตนที่สำคัญ โปรดทำตามคำแนะนำและเพิ่มการป้องกัน

ในตอนนี้ "กุญแจ" จะถูกสร้างขึ้นภายในอุปกรณ์ นั่นคือตัวตนของคุณเอง
**รายการบัญชีไม่มีอยู่บนเซิร์ฟเวอร์** ตัวตนอยู่ภายในอุปกรณ์ของคุณเท่านั้น
ประเด็นนี้จะสำคัญในบทการสำรองข้อมูล (บทที่ 9)

### เกี่ยวกับ "ตัวตนแบบใช้แล้วทิ้ง" ในอดีต

"ตัวตนแบบใช้แล้วทิ้ง" — ตัวตนที่ไม่มีวิธีกู้คืนใด ๆ เลย — ไม่มีอีกต่อไป ด้วยวิธีสร้างตัวตนในปัจจุบัน ตัวตนทุกตัวสามารถป้องกันได้ด้วยการสำรองข้อมูล

## 2. การเชื่อมต่อกับอีกฝ่าย

กดปุ่ม "เพิ่มเพื่อน" บนหน้าจอรายชื่อผู้ติดต่อ แล้วตัวเลือก 3 อย่างจะปรากฏ

- **เพิ่มผู้ติดต่อ**: ป้อน ID ของอีกฝ่าย หรือสแกน QR โค้ด
- **เชิญเพื่อน**: คัดลอกลิงก์คำเชิญแล้วส่งผ่านช่องทางติดต่อปกติของคุณ (อีเมล เป็นต้น) เมื่ออีกฝ่ายเปิดลิงก์และใส่ชื่อ ก็จะสนทนาได้ทันที
- **สร้างกลุ่ม**: เพียงใส่ชื่อกลุ่มก็สร้างได้ (บทที่ 4)

ID ของคุณเองจะแสดงในรูปแบบเต็มเมื่อเปิดโปรไฟล์ของตัวเอง และสามารถคัดลอกได้ตามนั้น สามารถส่งมอบ ID เต็ม ไม่ใช่แค่ ID แบบสั้นได้

หากอีกฝ่ายเปิดแอปอยู่เช่นกัน จะเชื่อมต่อกันโดยตรงและสนทนาได้

## 3. การสนทนา

- เพียงพิมพ์ข้อความแล้วส่ง รูปภาพ สติกเกอร์ และข้อมูลตำแหน่งก็ส่งได้เช่นกัน
- เปิด "+" ข้างช่องป้อน แล้วไฟล์แนบ ข้อความเสียง การป้อนด้วยเสียง ข้อมูลตำแหน่ง สติกเกอร์ การตั้งค่า "ไม่ต้องตอบกลับ" และอื่น ๆ จะปรากฏพร้อมกัน
- **การส่งไฟล์**: ในการสนทนาแบบ 1 ต่อ 1 สูงสุด 50MB ในกลุ่มจะเล็กกว่าคือประมาณ 50KB
- ไฟล์รูปแบบอันตราย เช่น ไฟล์ที่เรียกใช้งานได้ จะถูกบล็อกโดยอัตโนมัติ
- เมื่ออีกฝ่ายไม่ได้เปิดแอป ข้อความจะถูกเก็บไว้ในสภาพที่เข้ารหัสใน "กล่องรับฝาก" และจะส่งถึงเมื่ออีกฝ่ายเปิดแอป เซิร์ฟเวอร์ที่ขนส่งกล่องรับฝากอ่านเนื้อหาไม่ได้ จดหมายที่ไม่ได้รับการส่งมอบจะถูกลบโดยอัตโนมัติภายใน **สูงสุด 7 วัน**
- ประวัติการสนทนาสามารถส่งออกเป็นไฟล์หรือนำเข้าได้

### การอ่านหน้าจอ

- **สถานะการส่ง**: ดูได้จากเครื่องหมายข้างข้อความ ✓ หมายถึงส่งแล้ว ✓ ในวงกลมหมายถึงฝากไว้ในกล่องรับฝากแล้ว ✓✓ หมายถึงถึงอีกฝ่ายแล้ว อ่านแล้วคือเครื่องหมายสีน้ำเงิน และล้มเหลวคือเครื่องหมายสีแดง แยกแยะได้จากรูปร่างนอกจากสีด้วย
- **รายชื่อผู้ติดต่อ**: เวลาที่คุยกันล่าสุดจะแสดงเป็นเวลาสำหรับวันนี้ "เมื่อวาน" สำหรับเมื่อวาน เดือน/วันสำหรับปีนี้ และปี/เดือน/วันสำหรับก่อนหน้านั้น ผู้ติดต่อที่มีข้อความยังไม่ได้อ่านจะถูกเน้นชื่อและเวลา
- **ชื่อสำหรับผู้ติดต่อ**: เปิด "ข้อมูลผู้ติดต่อ" (ในเมนูคลิกขวาของผู้ติดต่อ หรือเมนู "⋮" ของการสนทนา) แล้วคุณสามารถตั้งชื่อของคุณเองสำหรับผู้ติดต่อรายนั้น (ชื่อเล่น) ได้ ชื่อเล่นจะถูกเก็บไว้บนอุปกรณ์นี้เท่านั้น และจะไม่ถูกส่งไปยังผู้ติดต่อหรือเซิร์ฟเวอร์ส่งต่อ เมื่อคุณตั้งชื่อเล่น ชื่อที่ผู้ติดต่อรายนั้นตั้งไว้สำหรับตนเองจะแสดงอยู่ข้าง ๆ ด้วยสีที่จางลงด้วย คุณสามารถปิดชื่อที่สองนั้นได้ด้วย "แสดงชื่อที่ผู้ติดต่อแต่ละรายตั้งไว้สำหรับตนเองด้วย" ในส่วน "ความเป็นส่วนตัว" ของการตั้งค่า
- **บัตรของคุณเอง**: ด้านบนสุดของรายการคือบัตรโปรไฟล์ของคุณเอง กดเพื่อเปิดโปรไฟล์ จะเลื่อนไปพร้อมกับรายการ
- **แท็บด้านล่างบนโทรศัพท์**: ที่ความกว้างของโทรศัพท์ แท็บห้าแท็บจะปรากฏที่ด้านล่างของหน้าจอ: "แชท", "การโทร", "รายชื่อ", "การ์ดของฉัน" และ "การตั้งค่า" แท็บใดจะแสดง สามารถเลือกทีละแท็บได้ที่ "แท็บด้านล่าง" ในการตั้งค่า (แชทจะแสดงเสมอ แม้คุณจะซ่อนแท็บการตั้งค่า คุณยังเปิดการตั้งค่าได้จากปุ่มเฟืองบนหน้าจอ)
- **ส่วนหัวของการสนทนา**: จากไอคอนค้นหาสามารถค้นหาภายในการสนทนาได้ จากเมนู "⋮" สามารถตรวจสอบหมายเลขความปลอดภัย ปิดการแจ้งเตือน ปักหมุด สร้างโพล และอื่น ๆ ได้

### คำสั่ง

พิมพ์ `/` ในช่องป้อน แล้วคำแนะนำคำสั่งจะปรากฏ พิมพ์ `/help` เพื่อดูรายการคำสั่งที่ใช้ได้ (71 ชนิด)
การดำเนินการบางอย่าง เช่น การตั้งค่าและการเชื่อมโยงอุปกรณ์ ทำผ่านคำสั่ง

## 4. กลุ่ม

- กลุ่มรองรับได้สูงสุด **1,000 คน**
- วิธีสร้างเพียงแค่ใส่ชื่อกลุ่มใน "สร้างกลุ่ม" ของ "เพิ่มเพื่อน" (สร้างด้วยคำสั่ง `/newgroup` ก็ได้) การเชิญทำผ่าน "ลิงก์คำเชิญกลุ่ม" ผู้ที่ได้รับลิงก์สามารถเข้าร่วมได้โดยใส่ชื่อ
- ในกลุ่มก็ส่งไฟล์ได้ แต่ขีดจำกัดเล็กคือประมาณ 50KB ข้อความเสียงยังส่งในกลุ่มไม่ได้
- หากมีสมาชิกที่ใช้แอปเวอร์ชันเก่า วิธีใหม่ที่ปลอดภัยกว่า (กลุ่ม v5) จะใช้ไม่ได้ในกลุ่มนั้น และจะมีคำเตือนปรากฏบนหน้าจอ เมื่อทุกคนอัปเดตเป็นเวอร์ชันล่าสุดจึงจะมีผล

## 5. การโทร

- โทรด้วยเสียงและโทรวิดีโอแบบ 1 ต่อ 1 ได้ มีการโทรกลุ่มด้วย (สูงสุด 8 คน)
- **รหัสยืนยันการโทร**: บนหน้าจอการโทรจะแสดงรหัสยืนยัน โปรดอ่านให้กันฟังกับอีกฝ่าย และตรวจสอบว่าตรงกันบนหน้าจอทั้งสองฝั่งหรือไม่ หากไม่ตรงกัน อาจมีใครบางคนกำลังดักฟังอยู่ระหว่างทาง ในกรณีนั้นโปรดวางสาย
- การโทรกลุ่มอาจเริ่มไม่ได้หากแอปของทุกคนไม่ใช่เวอร์ชันล่าสุด
- **ประวัติการโทร**: การโทรแบบตัวต่อตัวจะทิ้งประวัติไว้บนอุปกรณ์นี้เท่านั้น (อีกฝ่าย, การโทรเป็นขาออก / ขาเข้า / ไม่ได้รับ, เวลา และระยะเวลาการโทร ไม่มีสิ่งที่พูดถูกเก็บไว้เลย) ประวัติจะไม่ถูกส่งไปยังเซิร์ฟเวอร์หรืออีกฝ่ายเลย จะเก็บไว้สูงสุด 200 รายการ โดยรายการที่เก่าที่สุดจะถูกลบก่อน การโทรแบบกลุ่มจะไม่ปรากฏในประวัติ
- เปิดประวัติบนโทรศัพท์จากแท็บ "การโทร" เมื่อมีสายที่ไม่ได้รับซึ่งคุณยังไม่เห็น จะมีป้ายตัวเลขปรากฏบนแท็บการโทร และจะหายไปเมื่อคุณเปิดประวัติ จากแถวในประวัติ คุณสามารถเปิดการสนทนากับบุคคลนั้นหรือโทรกลับหาเขาได้ คุณสามารถลบประวัติทั้งหมดได้ด้วยปุ่มบนหน้าจอ
- **ประวัติการโทรไม่ได้เป็นส่วนหนึ่งของข้อมูลสำรอง** บนอุปกรณ์ใหม่ ประวัติจะเริ่มจากว่างเปล่า หากคุณไม่ต้องการให้เก็บประวัติ ให้ปิด "เก็บประวัติการโทรบนอุปกรณ์นี้" ในส่วน "ความเป็นส่วนตัว" ของการตั้งค่า และการบันทึกจะหยุดลงเอง

## 6. หลายอุปกรณ์ หลายบัญชี

- หากต้องการใช้ตัวตนเดียวกันบนหลายอุปกรณ์ ให้เชื่อมโยงอุปกรณ์เข้าด้วยกันด้วยคำสั่ง `/link`
- บัญชีสร้างได้หลายบัญชีและแยกใช้ได้ (เช่น แยกงานกับเรื่องส่วนตัว) ทั้งจำนวนอุปกรณ์และจำนวนบัญชีฟรีและไม่จำกัด
- **วิธีสร้างบัญชี**: กดปุ่ม "+" ข้างแท็บบัญชีที่ด้านบนสุดของรายชื่อผู้ติดต่อ ใส่ชื่อและเลือกอีโมจิไอคอน บัญชีใหม่จะถูกสร้างและสลับไปโดยอัตโนมัติ
- **การสลับบัญชี**: แท็บบัญชีจะแสดงที่ด้านบนสุดของรายชื่อผู้ติดต่อเสมอ กดแท็บเพื่อสลับ (บนคอมพิวเตอร์สามารถสลับด้วย Ctrl+1–9 ได้เช่นกัน) กดค้างที่แท็บเพื่อเปลี่ยนชื่อ เปลี่ยนไอคอน หรือลบ
- ผู้ติดต่อและกุญแจแยกกันสำหรับแต่ละบัญชี โปรดแลกเปลี่ยนผู้ติดต่ออีกครั้งสำหรับแต่ละบัญชี
- ภาษาจะถูกเลือกโดยอัตโนมัติจาก 51 ภาษา รวมถึงภาษาอังกฤษ ตามภาษาของอุปกรณ์ของคุณ

## 7. การตั้งค่าเพื่อความปลอดภัย

การตั้งค่าจะเปิดเป็นหน้าจอแยกต่างหาก บนโทรศัพท์ให้เปิดจากแท็บ "การตั้งค่า" ที่ด้านล่างของหน้าจอ บนคอมพิวเตอร์ให้เปิดจากปุ่มเฟืองบนหน้าจอ (เปิดด้วยคำสั่ง `/settings` ก็ได้) ใช้การย้อนกลับเพื่อกลับไปยังหน้าจอก่อนหน้า

- **ล็อกอัตโนมัติ**: มีการตั้งค่าให้ล็อกโดยอัตโนมัติเมื่อสลับแท็บ
- **ข้อความรหัสผ่านของกุญแจ**: กุญแจภายในอุปกรณ์สามารถป้องกันได้โดยห่อหุ้มด้วยข้อความรหัสผ่าน จะต้องป้อนเมื่อเปิดแอป
- **แสดงชื่อที่ผู้ติดต่อแต่ละรายตั้งไว้สำหรับตนเองด้วย**: ในส่วน "ความเป็นส่วนตัว" สำหรับผู้ติดต่อที่คุณตั้งชื่อเล่นไว้ คุณสามารถเลือกได้ว่าจะแสดงชื่อของพวกเขาเองควบคู่ไปด้วยหรือไม่ (บทที่ 3)
- **บล็อก**: สามารถบล็อกอีกฝ่ายที่ก่อกวนได้ การติดต่อจากฝ่ายที่ถูกบล็อกจะไม่มาถึง
- **จะเก็บประวัติการโทรหรือไม่**: ด้วย "เก็บประวัติการโทรบนอุปกรณ์นี้" ในส่วน "ความเป็นส่วนตัว" คุณสามารถหยุดการบันทึกประวัติการโทรได้ (บทที่ 5)
- **การแสดงแท็บด้านล่าง**: ในส่วน "แท็บด้านล่าง" คุณสามารถแสดงหรือซ่อนแท็บด้านล่างของโทรศัพท์ (การโทร / รายชื่อ / การ์ดของฉัน / การตั้งค่า) ทีละแท็บได้ แชทจะแสดงเสมอ

## 8. แบตเตอรี่และเหตุฉุกเฉิน (โหมดพลังงาน)

ในการตั้งค่า "โหมดพลังงาน" คุณสามารถเลือกวิธีใช้แบตเตอรี่ได้

- **อัตโนมัติ (ระดับแบตเตอรี่)**: สลับโดยอัตโนมัติตามปริมาณแบตเตอรี่ที่เหลือ
- **ปกติ**: ตามปกติ
- **ประหยัดพลังงาน**: เว้นระยะการตรวจสอบการส่งมอบเป็นอย่างบ่อยที่สุดทุก 60 วินาที และหยุดสัญญาณแสดงสถานะ
- **ฉุกเฉิน (สำหรับภัยพิบัติ)**: เว้นระยะการตรวจสอบการส่งมอบเป็นอย่างบ่อยที่สุดทุก 10 นาที ใช้เมื่อเกิดภัยพิบัติหรือเมื่อชาร์จไฟไม่ได้

สิ่งที่ทำให้แบตเตอรี่หมดไม่ใช่ปริมาณการสื่อสาร แต่เป็นจำนวนครั้งที่วิทยุต้องตื่นขึ้น ดังนั้นฝ่ายส่งจะไม่ถูกเว้นระยะ เว้นระยะเฉพาะฝ่ายฟังเท่านั้น การส่งยังคงออกไปทันทีตามปกติ เมื่อเริ่มชาร์จ มันจะขยับกลับหนึ่งขั้นไปทางที่เบากว่าโดยอัตโนมัติ

บนอุปกรณ์ที่ไม่สามารถอ่านระดับแบตเตอรี่โดยอัตโนมัติ (เช่น เบราว์เซอร์บน iPhone) "อัตโนมัติ" จะทำงานเหมือนปกติ และการเลือกด้วยตนเองจะทำงานตามที่เลือก

## 9. การสำรองข้อมูลและการกู้คืน (บทที่สำคัญที่สุด)

ตัวตนของ Breeze คือกุญแจภายในอุปกรณ์ของคุณเท่านั้น รายการบัญชีไม่มีอยู่บนเซิร์ฟเวอร์ และผู้สร้างก็ไม่มีกุญแจของคุณ
**หากทำอุปกรณ์หาย ตัวตนก็จะหายไปด้วย** สำหรับตัวตนที่สำคัญ โปรดสร้างการสำรองข้อมูลไว้เสมอ

การสำรองข้อมูลและการกู้คืนทำจากส่วน "การสำรองข้อมูลและการกู้คืน" ของการตั้งค่า (ปุ่มคือ "สร้างข้อมูลสำรอง" "กู้คืนข้อมูลสำรอง" และ "กู้คืนจากไฟล์") เมื่อเพิ่มผู้ติดต่อครั้งแรก จะมีบัตรแนะนำให้สำรองข้อมูลปรากฏขึ้นเพียงครั้งเดียว

### การสำรองข้อมูลอัตโนมัติ

การตั้งค่า "การสำรองข้อมูลอัตโนมัติ" เปิดอยู่ตั้งแต่เริ่มต้น เมื่อข้อมูลของคุณเปลี่ยนแปลง ข้อมูลสำรองที่เข้ารหัสจะถูกส่งไปยังเซิร์ฟเวอร์ส่งต่อที่คุณโฮสต์โดยอัตโนมัติ

- ไม่ได้ส่งทุกครั้งที่มีการเปลี่ยนแปลง: จะรอ 30 วินาทีหลังจากการเปลี่ยนแปลงครั้งสุดท้าย แล้วส่งทั้งหมดพร้อมกัน ความพยายามในการส่งจะเว้นระยะอย่างน้อย 15 นาที
- ขณะที่คุณออฟไลน์ จะไม่มีการส่งใด ๆ การเปลี่ยนแปลงจะถูกเก็บไว้และส่งเมื่อการเชื่อมต่อกลับมาและเมื่อคุณเปิดแอป
- สำหรับการส่งอัตโนมัติ คุณต้องป้อนวลีรหัสผ่านสำหรับการสำรองข้อมูลหนึ่งครั้งบนอุปกรณ์นั้น (เมื่อจำเป็น ปุ่ม "ป้อนวลีรหัสผ่าน" จะปรากฏในส่วนการตั้งค่า) **วลีรหัสผ่านจะไม่ถูกจัดเก็บ** จะถูกจดจำเฉพาะขณะที่แอปเปิดอยู่ และจะหายไปเมื่อคุณปิดแอป สำหรับตัวตนแบบกู้คืนอย่างง่าย ทันทีหลังจากที่คุณป้อนวลีรหัสผ่านตอนลงทะเบียนหรืออัปเดต การส่งจะทำงานได้ตามปกติ
- หากเซิร์ฟเวอร์ส่งต่อไม่รองรับการจัดเก็บข้อมูลสำรอง การสำรองข้อมูลอัตโนมัติจะไม่ทำงาน ซึ่งจะแสดงไว้ในส่วนการตั้งค่า
- สถานะ (การส่งสำเร็จครั้งล่าสุดเมื่อใด มีการเปลี่ยนแปลงที่รออยู่หรือไม่ การส่งล้มเหลวหรือไม่) จะแสดงไว้ในส่วนการตั้งค่า

### วิธีสร้างการสำรองข้อมูล (ด้วยตนเอง)

1. จาก "การสำรองข้อมูลและการกู้คืน" ในการตั้งค่า ให้เลือก "สร้างข้อมูลสำรอง"
2. ตั้งข้อความรหัสผ่านสำหรับการสำรองข้อมูล (6 ตัวอักษรขึ้นไป)
3. เลือกปลายทางที่จะบันทึก
   - **บันทึกลงไฟล์**: เก็บไฟล์สำรองข้อมูลไว้กับตัวเอง (แนะนำ)
   - **บันทึกลงเซิร์ฟเวอร์ส่งต่อ**: ใช้ได้เฉพาะเมื่อผู้ให้บริการของเซิร์ฟเวอร์ส่งต่อนั้นเปิดใช้งานไว้เท่านั้น ใช้กับเซิร์ฟเวอร์ส่งต่อเริ่มต้นไม่ได้ มีระยะเวลาการเก็บรักษา โปรดนำกลับมาภายในระยะเวลา

เนื้อหาของการสำรองข้อมูลถูกเข้ารหัสไว้ เซิร์ฟเวอร์ที่ปลายทางการบันทึกจัดการเฉพาะข้อความที่เข้ารหัสเท่านั้น

### วิธีกู้คืน

บนอุปกรณ์ใหม่ ให้กู้คืนโดยใช้ไฟล์สำรองข้อมูล (หรือการสำรองข้อมูลบนเซิร์ฟเวอร์ส่งต่อ) และข้อความรหัสผ่านที่ตั้งไว้

หากคุณเพิ่งนำตัวตนกลับมาด้วยวลีสำหรับกู้คืน และมีข้อมูลสำรองของตัวตนนั้นอยู่บนเซิร์ฟเวอร์ส่งต่อ ระบบจะค้นพบโดยอัตโนมัติและถามคุณด้วย "พบข้อมูลสำรอง" หากคุณกู้คืน ข้อมูลบนอุปกรณ์นั้นจะถูกแทนที่ด้วยเนื้อหาของข้อมูลสำรอง

### การย้ายไปยังอุปกรณ์ใหม่

กดปุ่ม "ย้ายไปยังอุปกรณ์ใหม่" ในส่วน "การสำรองข้อมูลและการกู้คืน" ของการตั้งค่า แล้วขั้นตอนจะปรากฏ

1. บนอุปกรณ์ปัจจุบันของคุณ ให้เก็บข้อมูลสำรองไว้บนเซิร์ฟเวอร์ส่งต่อ (การสำรองข้อมูลอัตโนมัติ หรือ "สร้างข้อมูลสำรอง")
2. บนอุปกรณ์ใหม่ ให้เลือกวิธีกู้คืนบนหน้าจอแรก และป้อนวลีสำหรับกู้คืนของคุณ (หรือชื่อบัญชีและวลีรหัสผ่านของคุณ)
3. เมื่อตัวตนของคุณกลับมา ข้อมูลสำรองบนเซิร์ฟเวอร์จะถูกค้นพบโดยอัตโนมัติและมีการเสนอกู้คืน

ไม่ต้องใช้สายเคเบิลหรือการส่งมอบไฟล์

### ข้อควรระวัง

- **หากลืมข้อความรหัสผ่าน จะไม่สามารถกู้คืนได้** ผู้สร้างก็แก้ไขให้ไม่ได้ โปรดจดข้อความรหัสผ่านไว้ในที่อื่น
- การป้อนวลีรหัสผ่านสำหรับการสำรองข้อมูลอัตโนมัติจำเป็นต้องทำบนอุปกรณ์แต่ละเครื่อง บนอุปกรณ์ใหม่ โปรดป้อนอีกครั้ง
- โปรดสร้างการสำรองข้อมูลด้วยตนเองใหม่เมื่อตัวตนของคุณเพิ่มขึ้นหรือเมื่อคุณเปลี่ยนอุปกรณ์
- ประวัติการโทรไม่ได้เป็นส่วนหนึ่งของข้อมูลสำรอง เมื่อคุณเปลี่ยนอุปกรณ์ ประวัติการโทรจะไม่ย้ายไปยังอุปกรณ์ใหม่

## 10. กล่องรับฝาก และแนวคิดเรื่องค่าใช้จ่าย

- จดหมายขณะที่อีกฝ่ายออฟไลน์จะถูกเก็บไว้ในสภาพที่เข้ารหัสใน "กล่องรับฝาก" ของเซิร์ฟเวอร์ส่งต่อ (สูงสุด 7 วัน)
- เซิร์ฟเวอร์ส่งต่อมีขีดจำกัดเพื่อป้องกันการใช้ในทางที่ผิด (ปริมาณและความถี่ที่รับฝากได้) เมื่อถึงขีดจำกัด จะรับฝากจดหมายใหม่ไม่ได้ในช่วงนั้น แต่ **จดหมายที่มาถึงแล้วจะไม่หายไป** บนหน้าจอจะแสดงเหตุผลและเวลาที่ต้องรอ
- ขีดจำกัดสามารถกำหนดเองได้หากติดตั้งบนเซิร์ฟเวอร์ของตัวเอง

ขอบเขตของบันทึกที่เหลืออยู่ฝั่งเซิร์ฟเวอร์ (ทั้งหมดถูกลบโดยอัตโนมัติ และอ่านเนื้อหาไม่ได้):

| สิ่งของ | ระยะเวลาที่เหลืออยู่ |
|---|---|
| จดหมายที่ยังไม่ส่งมอบ | สูงสุด 7 วัน |
| สัญญาณการเชื่อมต่อ | 5 นาที |
| บันทึกที่อยู่และอุปกรณ์ | 90 วัน |
| ข้อมูลกลุ่ม / การสมัครรับการแจ้งเตือน | 30 วัน |

## 11. วิธีอัปเดต (เวอร์ชันเดสก์ท็อป)

1. เมื่อมีเวอร์ชันใหม่ จะมีประกาศปรากฏบนหน้าจอ
2. เมื่อกด "ดาวน์โหลด" จะไปรับเวอร์ชันใหม่มา (จะไม่ติดตั้งโดยอัตโนมัติ)
3. เมื่อดาวน์โหลดเสร็จ ให้กด "ติดตั้ง" แล้วเริ่มใหม่

หากการอัปเดตล้มเหลวระหว่างทาง (เช่น ค่าตรวจสอบของไฟล์ไม่ตรงกัน) **จะหยุดการอัปเดตและแสดงเหตุผลบนหน้าจอ** ไม่สามารถย้อนกลับไปเวอร์ชันเก่าได้

|---|---|
| ส่งข้อความไม่ได้ | โปรดตรวจสอบว่าเวลาของอุปกรณ์คลาดเคลื่อนหรือไม่ หากเวลาคลาดเคลื่อน การส่งจะล้มเหลว |
| ไม่ถึงอีกฝ่าย | จะรออยู่ในกล่องรับฝากจนกว่าอีกฝ่ายจะเปิดแอป (สูงสุด 7 วัน) |
| ส่งไฟล์ไม่ได้ | โปรดตรวจสอบว่าเกินขีดจำกัดขนาด (แบบ 1 ต่อ 1 คือ 50MB กลุ่มประมาณ 50KB) หรือไม่ หรือถูกบล็อกเพราะเป็นรูปแบบอันตรายหรือไม่ |
| รหัสยืนยันการโทรไม่ตรงกัน | โปรดวางสายแล้วโทรใหม่ อย่าสนทนาต่อในสภาพที่ไม่ตรงกัน |
| ลืมข้อความรหัสผ่าน | ไม่สามารถกู้คืนได้ โปรดสร้างตัวตนใหม่และแจ้งอีกฝ่ายอีกครั้ง |
| ทำอุปกรณ์หาย | หากมีการสำรองข้อมูล สามารถกู้คืนบนอุปกรณ์ใหม่ได้ หากไม่มี จะกลายเป็นตัวตนใหม่ |

การรายงานข้อบกพร่องโปรดส่งไปที่ [หน้า Issue](https://github.com/shizukutanaka/Breeze/issues)

## 13. คำสัญญาของ Breeze

- ไม่แสดงโฆษณา ทั้งในแอปและที่ใดก็ตาม
- ไม่ติดตาม ไม่มีการวิเคราะห์การใช้งาน กลไกโฆษณา หรือการขายข้อมูลเลย
- ผู้สร้างไม่ถือข้อมูลของผู้ใช้ ฝั่งเซิร์ฟเวอร์ไม่มีแม้แต่รายการบัญชี
- การสนทนาถูกเข้ารหัสระหว่างอุปกรณ์ เซิร์ฟเวอร์จัดการเฉพาะซองจดหมายที่อ่านไม่ได้เท่านั้น

การเปรียบเทียบโดยละเอียดกับแอปส่งข้อความอื่นเขียนไว้ใน "หน้าเปรียบเทียบ" ของที่เก็บ รวมทั้งจุดที่ Breeze ด้อยกว่า (จำนวนผู้ใช้ การยังไม่ได้รับการตรวจสอบจากภายนอก เป็นต้น) ด้วย
