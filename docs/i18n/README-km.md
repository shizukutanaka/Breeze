**កម្មវិធីផ្ញើសារដែលបានអ៊ីនគ្រីប — មិនត្រូវការលេខទូរស័ព្ទ មិនត្រូវការចុះឈ្មោះ។**
ខ្លឹមសារនៃការសន្ទនាអាចអានបានតែអ្នកផ្ញើ និងអ្នកទទួលប៉ុណ្ណោះ។ សូម្បីតែម៉ាស៊ីនមេដែលដឹកជញ្ជូននៅកណ្តាលផ្លូវក៏មិនអាចអានបានដែរ។
មុខងារទាំងអស់ឥតគិតថ្លៃ ហើយគ្មានការផ្សាយពាណិជ្ជកម្ម។

នេះមិនមែនជាទំព័របណ្តាញទេ ប៉ុន្តែជាសូហ្វវែរដែលត្រូវដំឡើង និងប្រើប្រាស់ (Windows / Mac / Linux / Android / iPhone / កម្មវិធីរុករក)។

## ដើម្បីប្រើប្រាស់ សូមដាក់វានៅលើម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នក

Breeze មិនមាន "ម៉ាស៊ីនមេរបស់ក្រុមហ៊ុនប្រតិបត្តិការ" ទេ។ **ដើម្បីប្រើប្រាស់ អ្នកត្រូវរៀបចំទីកន្លែង (ម៉ាស៊ីនមេ) ដោយខ្លួនឯង ហើយដាក់ Breeze នៅទីនោះ។ នេះគឺជាវិធីប្រើប្រាស់ជាផ្លូវការ។**

- ការដំឡើងស្តង់ដារប្រើ Cloudflare ដូច្នេះ **គណនី Cloudflare គឺត្រូវការ**។ ជំហាននានាមាននៅក្នុង [មគ្គុទ្ទេសក៍ដំឡើង](SELF_HOSTING-km.md) (ភាសាផ្សេងទៀតអាចជ្រើសរើសបានពីផ្នែកខាងលើនៃមគ្គុទ្ទេសក៍)។
- កម្មវិធី (Windows / Mac / Linux / Android / iPhone) អាចយកបានពី [ទំព័រទាញយក](https://github.com/shizukutanaka/Breeze/releases/latest) ហើយប្រើប្រាស់ដោយភ្ជាប់ទៅម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នក។
- **អំពីការដំឡើងគំរូ (ការជូនដំណឹងដោយស្មោះត្រង់)**៖ មានគំរូសម្រាប់ផ្ទៀងផ្ទាត់ប្រតិបត្តិការ (https://breeze-469.pages.dev/) ត្រូវបានដាក់ទុក។ សូហ្វវែរដែលដាក់នៅទីនោះគឺដូចគ្នា ប៉ុន្តែសម្រាប់ការប្រើប្រាស់ពិតប្រាកដ សូមប្រើម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នក។ គំរូអាចផ្លាស់ប្តូរ ឬឈប់ដំណើរការដោយមិនបានជូនដំណឹងជាមុន។ អ្វីដែលអ្នកដាក់នៅលើម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នកនឹងមិនរងផលប៉ះពាល់ពីការបញ្ឈប់គំរូនោះទេ។

វិធីប្រើប្រាស់លម្អិតមាននៅក្នុង [សៀវភៅណែនាំ](MANUAL-km.md) (ភាសាផ្សេងទៀតអាចជ្រើសរើសបានពីផ្នែកខាងលើនៃសៀវភៅណែនាំ)។

## វិធីប្រើប្រាស់ (៣ ជំហាន)

1. បើក Breeze ដែលអ្នកបានដាក់នៅលើម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នក (ឬអាសយដ្ឋានដែលអ្នកដាក់បានប្រាប់អ្នក) ហើយចុច "ចាប់ផ្តើមដោយលេខសម្គាល់ចៃដន្យ" (អ្នកអាចបញ្ចូលឈ្មោះបានប្រសិនបើអ្នកចង់)។ ត្រឹមតែប៉ុណ្ណឹង ការរៀបចំបានបញ្ចប់ (មិនត្រូវការចុះឈ្មោះ មិនត្រូវការលេខទូរស័ព្ទ)។ នៅពេលនោះ "សោ" មួយត្រូវបានបង្កើតឡើងនៅខាងក្នុងឧបករណ៍ ហើយសោនោះក្លាយជាអត្តសញ្ញាណរបស់អ្នក។
2. ផ្តល់លេខសម្គាល់ ឬកូដ QR របស់អ្នកទៅអ្នកដែលអ្នកចង់និយាយជាមួយ។
3. ប្រសិនបើភាគីម្ខាងទៀតក៏កំពុងបើកកម្មវិធីដែរ អ្នកអាចភ្ជាប់ដោយផ្ទាល់ និងសន្ទនាបាន។ ប្រសិនបើពួកគេមិនបានបើក សារនឹងត្រូវដាក់ក្នុងស្ថានភាពបានអ៊ីនគ្រីបនៅក្នុង "ប្រអប់រក្សាទុក" ហើយនឹងត្រូវបានបញ្ជូននៅពេលពួកគេបើក។ ម៉ាស៊ីនមេដែលដឹកជញ្ជូនប្រអប់រក្សាទុកមិនអាចអានខ្លឹមសារបានទេ។ សំបុត្រដែលមិនបានបញ្ជូននឹងត្រូវលុបដោយស្វ័យប្រវត្តិក្នុងរយៈពេលអតិបរមា ៧ ថ្ងៃ។

## ការសន្យា (អ្វីដែលយើងមិនធ្វើ)

- **យើងមិនបង្ហាញការផ្សាយពាណិជ្ជកម្មទេ។** មិននៅក្នុងកម្មវិធី មិននៅកន្លែងណាក៏ដោយ។
- **យើងមិនតាមដានទេ។** គ្មានការវិភាគការប្រើប្រាស់ គ្មានយន្តការផ្សាយពាណិជ្ជកម្ម គ្មានការលក់ទិន្នន័យឡើយ។
- **អ្នកបង្កើតមិនកាន់កាប់ទិន្នន័យរបស់អ្នកប្រើប្រាស់ទេ។** នៅខាងម៉ាស៊ីនមេ សូម្បីតែបញ្ជីគណនីក៏មិនមានដែរ។ អត្តសញ្ញាណរបស់អ្នកគឺគ្រាន់តែជាសោនៅខាងក្នុងឧបករណ៍របស់អ្នកប៉ុណ្ណោះ។
- **ការសន្ទនាត្រូវបានអ៊ីនគ្រីបរវាងឧបករណ៍។** ម៉ាស៊ីនមេដោះស្រាយតែស្រោមសំបុត្រដែលវាមិនអាចអានបានប៉ុណ្ណោះ។

យើងក៏សរសេរអំពីវិសាលភាពដោយស្មោះត្រង់ផងដែរ។ ដើម្បីបញ្ជូន ម៉ាស៊ីនមេរក្សាទុករបស់មួយចំនួនក្នុងរយៈពេលខ្លី (ស្រោមសំបុត្រដែលមិនទាន់បានបញ្ជូនអតិបរមា ៧ ថ្ងៃ សញ្ញាតភ្ជាប់ ៥ នាទី កំណត់ត្រាអាសយដ្ឋាន និងឧបករណ៍ ៩០ ថ្ងៃ ព័ត៌មានក្រុម និងការជាវការជូនដំណឹង ៣០ ថ្ងៃ។ ទាំងអស់ត្រូវបានលុបដោយស្វ័យប្រវត្តិ ហើយខ្លឹមសារមិនអាចអានបាន)។ ការបម្រុងទុកទៅពពកត្រូវបានបិទនៅពេលចាប់ផ្តើម។ ប្រសិនបើអ្នកដាក់វានៅលើម៉ាស៊ីនមេផ្ទាល់ខ្លួនរបស់អ្នក ការរក្សាទុកនោះក៏ស្ថិតនៅក្រោមការគ្រប់គ្រងផ្ទាល់ខ្លួនរបស់អ្នកផងដែរ។

## English

Breeze is an end-to-end encrypted messenger with no phone number, no registration, and no ads — every feature is free. There is no company server: to use Breeze, you host it on your own server and connect the apps to it. Your identity is a key pair on your device; relays handle only sealed envelopes they cannot read. Full text in English: [README-en.md](README-en.md). The full, sourced comparison against Signal and LINE — including where Breeze loses — is in [../COMPARISON.md](../COMPARISON.md).
