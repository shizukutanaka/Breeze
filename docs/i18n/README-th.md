## หากต้องการใช้ ให้ติดตั้งบนเซิร์ฟเวอร์ของตัวเอง

Breeze ไม่มี "เซิร์ฟเวอร์ของบริษัทผู้ให้บริการ" **หากต้องการใช้ คุณต้องเตรียมสถานที่ (เซิร์ฟเวอร์) ด้วยตัวเอง และติดตั้ง Breeze ไว้ที่นั่น นี่คือวิธีใช้งานอย่างเป็นทางการ**

- การติดตั้งแบบมาตรฐานใช้ Cloudflare ดังนั้น **จำเป็นต้องมีบัญชี Cloudflare** ขั้นตอนอยู่ใน [คู่มือการติดตั้ง](SELF_HOSTING-th.md) (สามารถเลือกภาษาอื่นได้จากส่วนต้นของคู่มือ)
- แอป (Windows / Mac / Linux / Android / iPhone) ดาวน์โหลดได้จาก [หน้าดาวน์โหลด](https://github.com/shizukutanaka/Breeze/releases/latest) แล้วเชื่อมต่อกับเซิร์ฟเวอร์ของตัวเองเพื่อใช้งาน
- **เกี่ยวกับตัวอย่างติดตั้ง (ประกาศอย่างตรงไปตรงมา)**: มีตัวอย่างสำหรับตรวจสอบการทำงาน (https://breeze-469.pages.dev/) ติดตั้งไว้ ซอฟต์แวร์ที่ติดตั้งไว้เป็นตัวเดียวกัน แต่สำหรับการใช้งานจริง โปรดใช้เซิร์ฟเวอร์ของตัวเอง ตัวอย่างอาจเปลี่ยนแปลงหรือหยุดให้บริการโดยไม่แจ้งล่วงหน้า สิ่งที่ติดตั้งบนเซิร์ฟเวอร์ของตัวเองจะไม่ได้รับผลกระทบจากการหยุดของตัวอย่าง

วิธีใช้งานโดยละเอียดอยู่ใน [คู่มือการใช้งาน](MANUAL-th.md) (สามารถเลือกภาษาอื่นได้จากส่วนต้นของคู่มือ)

## วิธีใช้งาน (3 ขั้นตอน)

1. เปิด Breeze ที่ติดตั้งบนเซิร์ฟเวอร์ของตัวเอง (หรือที่อยู่ที่ได้รับแจ้งจากผู้ที่ติดตั้งไว้) แล้วกด "เริ่มต้นด้วย ID สุ่ม" (สามารถใส่ชื่อได้หากต้องการ) เพียงเท่านี้ก็พร้อมใช้งาน (ไม่ต้องลงทะเบียน ไม่ต้องใช้เบอร์โทรศัพท์) ในตอนนี้ "กุญแจ" จะถูกสร้างขึ้นภายในอุปกรณ์ และกุญแจนั้นจะกลายเป็นตัวตนของคุณ
2. ส่ง ID หรือ QR โค้ดของคุณให้คนที่คุณอยากคุยด้วย
3. หากอีกฝ่ายเปิดแอปอยู่เช่นกัน จะเชื่อมต่อกันโดยตรงและสนทนาได้ หากอีกฝ่ายไม่ได้เปิด ข้อความจะถูกเก็บไว้ในสภาพที่เข้ารหัสใน "กล่องรับฝาก" และจะส่งถึงเมื่ออีกฝ่ายเปิดแอป เซิร์ฟเวอร์ที่ขนส่งกล่องรับฝากอ่านเนื้อหาไม่ได้ จดหมายที่ไม่ได้รับการส่งมอบจะถูกลบโดยอัตโนมัติภายในสูงสุด 7 วัน

## คำสัญญา (สิ่งที่เราจะไม่ทำ)

- **ไม่แสดงโฆษณา** ทั้งในแอปและที่ใดก็ตาม
- **ไม่ติดตาม** ไม่มีการวิเคราะห์การใช้งาน กลไกโฆษณา หรือการขายข้อมูลเลย
- **ผู้สร้างไม่ถือข้อมูลของผู้ใช้** ฝั่งเซิร์ฟเวอร์ไม่มีแม้แต่รายการบัญชี ตัวตนของคุณคือกุญแจภายในอุปกรณ์ของคุณเท่านั้น
- **การสนทนาถูกเข้ารหัสระหว่างอุปกรณ์** เซิร์ฟเวอร์จัดการเฉพาะซองจดหมายที่อ่านไม่ได้เท่านั้น

เราจะเขียนขอบเขตอย่างตรงไปตรงมาด้วย เพื่อการส่งมอบ เซิร์ฟเวอร์จะเก็บรักษาบางสิ่งไว้ชั่วคราว (ซองจดหมายที่ยังไม่ส่งมอบสูงสุด 7 วัน สัญญาณการเชื่อมต่อ 5 นาที บันทึกที่อยู่และอุปกรณ์ 90 วัน ข้อมูลกลุ่มและการสมัครรับการแจ้งเตือน 30 วัน ทั้งหมดจะถูกลบโดยอัตโนมัติ และอ่านเนื้อหาไม่ได้) การสำรองข้อมูลไปยังคลาวด์ถูกปิดไว้ในตอนแรก หากติดตั้งบนเซิร์ฟเวอร์ของตัวเอง การเก็บรักษานั้นก็อยู่ภายใต้การควบคุมของคุณเองเช่นกัน

## สิ่งที่ทำได้

- การสนทนาแบบ 1 ต่อ 1 และการสนทนากลุ่ม (สูงสุด 1,000 คน)
- การโทรด้วยเสียงและการโทรวิดีโอ (การโทรกลุ่มสูงสุด 8 คน)
- ประวัติการโทร (เก็บไว้บนอุปกรณ์นี้เท่านั้น: เฉพาะอีกฝ่าย ทิศทาง เวลา และระยะเวลาการโทร — ไม่มีสิ่งที่พูดเลย ไม่เคยส่งไปยังเซิร์ฟเวอร์หรืออีกฝ่าย)
- การส่งไฟล์ (แบบ 1 ต่อ 1 สูงสุด 50MB ในกลุ่มก็ส่งได้ แต่ขีดจำกัดขนาดจะเล็กกว่า)
- การใช้หลายอุปกรณ์และหลายบัญชี (เช่น แยกงานกับเรื่องส่วนตัว ทั้งจำนวนอุปกรณ์และจำนวนบัญชีฟรีและไม่จำกัด)
- การสำรองข้อมูลอัตโนมัติ (เมื่อมีบางอย่างเปลี่ยนแปลง ข้อมูลสำรองที่เข้ารหัสจะถูกบันทึกไปยังเซิร์ฟเวอร์ของตัวเองโดยอัตโนมัติ บนอุปกรณ์ใหม่ เมื่อคุณกู้คืนตัวตนแล้ว ข้อมูลสำรองจะถูกค้นพบโดยอัตโนมัติและเสนอให้คุณ การตั้งค่ายังแนะนำการย้ายไปยังอุปกรณ์ใหม่ด้วย)
- ชื่อที่คุณเลือกสำหรับผู้ติดต่อแต่ละราย (คุณสามารถเปลี่ยนชื่อผู้ติดต่อแต่ละรายได้ โดยเก็บไว้บนอุปกรณ์นี้เท่านั้น คุณยังสามารถเลือกได้ว่าจะแสดงชื่อที่ผู้ติดต่อแต่ละรายตั้งไว้สำหรับตนเองหรือไม่)
- 51 ภาษา (อังกฤษบวกไฟล์ภาษาอีก 50 ภาษา) เลือกอัตโนมัติตามภาษาของอุปกรณ์ของคุณ
- โปรไฟล์พร้อมรูปภาพ สติกเกอร์ การแชร์ตำแหน่ง
- การใช้งานด้วยคำสั่ง เช่น `/help` (71 ชนิด)
- โหมดพลังงานตามแบตเตอรี่ของคุณ (อัตโนมัติ / ปกติ / ประหยัดพลังงาน / ฉุกเฉิน) เมื่อแบตเตอรี่ลดลง การตรวจสอบการส่งมอบจะถูกเว้นระยะเพื่อให้แบตเตอรี่ใช้ได้นานขึ้น เป็นการเตรียมพร้อมสำหรับภัยพิบัติและเวลาที่ชาร์จไฟไม่ได้
- แท็บด้านล่างบนโทรศัพท์ (แชท / การโทร / รายชื่อ / การ์ดของฉัน / การตั้งค่า แท็บใดจะแสดงสามารถเลือกได้ในการตั้งค่า)
- หน้าจอที่อ่านง่าย (ใส่ใจความคมชัดของสี ขนาดตัวอักษร และการใช้งานด้วยแป้นพิมพ์เพียงอย่างเดียว)

## ความแตกต่างจากแอปส่งข้อความอื่น

| | Breeze | แอปส่งข้อความส่วนใหญ่ |
|---|--------|--------|
| การลงทะเบียน | ไม่จำเป็น (ตัวตนคือกุญแจในอุปกรณ์) | ต้องใช้เบอร์โทรศัพท์ |
| เซิร์ฟเวอร์ | อ่านเนื้อหาไม่ได้ | อยู่บนพื้นฐานความไว้วางใจในบริษัทผู้ให้บริการ |
| การติดตั้งบนเซิร์ฟเวอร์ของตัวเอง | เป็นเงื่อนไขพื้นฐาน (เป็นสิ่งที่ติดตั้งแล้วใช้) | ทำไม่ได้ |
| การเปิดเผยภายใน | เปิดเผยทั้งหมด (สัญญาอนุญาต MIT) | ส่วนใหญ่ไม่เปิดเผย |
| สถานที่ของข้อมูล | ภายในอุปกรณ์ของคุณ | บนเซิร์ฟเวอร์ของบริษัทผู้ให้บริการ |

การเปรียบเทียบโดยละเอียดกับ Signal และ LINE อยู่ใน [หน้าเปรียบเทียบ (ภาษาอังกฤษ)](../COMPARISON.md) ข้อกล่าวอ้างแต่ละข้อของ Breeze มี "วิธีตรวจสอบ" กำกับไว้ และจุดที่ Breeze ด้อยกว่า (จำนวนผู้ใช้ การยังไม่ได้รับการตรวจสอบจากภายนอก เป็นต้น) ก็เขียนไว้โดยไม่ปิดบัง

## ค่าใช้จ่ายเมื่อติดตั้งบนเซิร์ฟเวอร์ของตัวเอง

Breeze ทำงานได้ในขอบเขตฟรีของ Cloudflare ไม่ต้องใช้บัตรเครดิต

| รายการ | ขอบเขตฟรี | กรณีเสียเงิน |
|-----------|-----------|-------------|
| สถานที่ติดตั้ง | Cloudflare Pages (ฟรี) | — |
| การประมวลผล | สูงสุดวันละ 100,000 ครั้ง | สูงสุดเดือนละ 10 ล้านครั้ง |
| การจัดเก็บ | ต่อวัน อ่านสูงสุด 100,000 ครั้ง เขียนสูงสุด 1,000 ครั้ง | ต่อเดือน อ่าน 10 ล้านครั้ง เขียน 1 ล้านครั้ง |
| การส่งต่อการโทร | ฟรีถึง 20GB | 0.05 ดอลลาร์ต่อ 1GB |
| โดเมนของตัวเอง | ไม่จำเป็น (มีที่อยู่ฟรีให้) | ปีละ 10 ดอลลาร์ |
| **รวม** | **เดือนละ 0 ดอลลาร์** (ใช้งานเบา ๆ ได้ถึงประมาณ 20–40 คน) | **เริ่มต้นเดือนละ 5 ดอลลาร์** (ใช้งานเบา ๆ ขนาดประมาณ 100 คน ที่ขนาด 1,000 คน ขึ้นอยู่กับการใช้งาน เดือนละ 34–222 ดอลลาร์) |

การเติบโตของค่าใช้จ่ายในขนาดใหญ่ และ "ทำไมผู้ให้บริการเพียงคนเดียวจึงไม่ต้องแบกรับค่าใช้จ่ายทั้งหมด" อยู่ใน [แนวคิดเรื่องค่าใช้จ่ายและความยั่งยืน (ภาษาอังกฤษ)](../SUSTAINABILITY.md) และการคำนวณที่เป็นพื้นฐานอยู่ใน [แบบจำลองค่าใช้จ่าย (ภาษาอังกฤษ)](../COST_MODEL.md)

การติดตั้งเริ่มจากคำสั่งเดียวนี้ (รายละเอียดอยู่ใน [คู่มือการติดตั้ง](SELF_HOSTING-th.md))

```bash
wrangler pages deploy . --project-name=breeze
```

## รายละเอียดทางเทคนิค (สำหรับนักพัฒนา)

### วิธีการเข้ารหัส

| บทบาท | วิธีการ |
|-------|-----------|
| การแลกเปลี่ยนกุญแจ | X25519 (สำรอง: P-256) |
| ลายเซ็น | Ed25519 (สำรอง: HMAC-SHA256) |
| การเข้ารหัส | AES-256-GCM |
| การอนุมานกุญแจ | HKDF-SHA256 |
| การอัปเดตกุญแจการสนทนา | Double Ratchet (วิธีเดียวกับ Signal) |
| กุญแจกลุ่ม | Sender Key |
| การซ่อนผู้ส่งจากตัวส่งต่อ | Sealed Sender |

เอกสารหลักของการออกแบบคือ [เอกสารข้อกำหนด SPEC.md](../../SPEC.md) และช่องทางรายงานจุดอ่อนและนโยบายอยู่ใน [SECURITY.md](../../SECURITY.md)

## English

Breeze is an end-to-end encrypted messenger with no phone number, no registration, and no ads — every feature is free. There is no company server: to use Breeze, you host it on your own server and connect the apps to it. Your identity is a key pair on your device; relays handle only sealed envelopes they cannot read. Full text in English: [README-en.md](README-en.md). The full, sourced comparison against Signal and LINE — including where Breeze loses — is in [../COMPARISON.md](../COMPARISON.md).
