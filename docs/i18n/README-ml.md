**ഫോൺ നമ്പറോ രജിസ്ട്രേഷനോ ആവശ്യമില്ലാത്ത, എൻക്രിപ്റ്റ് ചെയ്ത ഒരു മെസഞ്ചർ.**
സംഭാഷണത്തിലെ ഉള്ളടക്കം അയച്ചയാൾക്കും സ്വീകരിക്കുന്നയാൾക്കും മാത്രമേ വായിക്കാൻ കഴിയൂ. ഇടയിൽ അത് കൊണ്ടുപോകുന്ന സെർവറിന് പോലും അത് വായിക്കാൻ കഴിയില്ല.
എല്ലാ സവിശേഷതകളും സൗജന്യമാണ്, പരസ്യങ്ങളൊന്നുമില്ല.

ഇതൊരു വെബ് പേജല്ല — ഇത് ഇൻസ്റ്റാൾ ചെയ്ത് ഉപയോഗിക്കുന്ന സോഫ്റ്റ്‌വെയറാണ് (Windows / Mac / Linux / Android / iPhone / ബ്രൗസർ).

![Breeze Messenger screenshot — the main window right after creating an identity](../images/screenshot.png)

## ഇത് ഉപയോഗിക്കാൻ, നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഇത് ഹോസ്റ്റ് ചെയ്യുക

Breeze-ന് "കമ്പനി സെർവർ" ഇല്ല. **ഇത് ഉപയോഗിക്കാൻ, നിങ്ങൾ തന്നെ ഒരു ഹോസ്റ്റിംഗ് സ്ഥലം (സെർവർ) ഒരുക്കി, അവിടെ Breeze സ്ഥാപിക്കണം. ഇതാണ് ഇത് ഉപയോഗിക്കാനുള്ള ഔദ്യോഗിക മാർഗം.**

- സൗജന്യ ടയർ മതിയാകും. ഇത് Cloudflare-ന്റെ സൗജന്യ ടയറിൽ പ്രവർത്തിക്കുന്നു, ക്രെഡിറ്റ് കാർഡ് ആവശ്യമില്ല. ഘട്ടങ്ങൾ [സജ്ജീകരണ ഗൈഡിൽ](SELF_HOSTING-ml.md) ഉണ്ട് (മറ്റ് ഭാഷകൾ ഗൈഡിന്റെ മുകളിൽ നിന്ന് തിരഞ്ഞെടുക്കാം).
- ആപ്പ് (Windows / Mac / Linux / Android / iPhone) [ഡൗൺലോഡ് പേജിൽ](https://github.com/shizukutanaka/Breeze/releases/latest) നിന്ന് എടുത്ത്, നിങ്ങളുടെ സ്വന്തം സെർവറുമായി ബന്ധിപ്പിച്ച് ഉപയോഗിക്കുക.
- **ഡെമോ ഹോസ്റ്റിനെക്കുറിച്ച് (സത്യസന്ധമായ ഒരു കുറിപ്പ്)**: പരീക്ഷിച്ചു നോക്കാൻ ഒരു ഡെമോ (https://breeze-469.pages.dev/) ലഭ്യമാണ്. ഇത് അതേ സോഫ്റ്റ്‌വെയർ തന്നെയാണ്, പക്ഷേ യഥാർത്ഥ ഉപയോഗത്തിന് ദയവായി നിങ്ങളുടെ സ്വന്തം സെർവർ ഉപയോഗിക്കുക. ഡെമോ അറിയിപ്പില്ലാതെ മാറുകയോ നിലയ്ക്കുകയോ ചെയ്യാം. നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഹോസ്റ്റ് ചെയ്ത Breeze-നെ ഡെമോ നിലയ്ക്കുന്നത് ബാധിക്കില്ല.

വിശദമായ ഉപയോഗ നിർദ്ദേശങ്ങൾക്ക്, [മാനുവൽ](MANUAL-ml.md) കാണുക (മറ്റ് ഭാഷകൾ മാനുവലിന്റെ മുകളിൽ നിന്ന് തിരഞ്ഞെടുക്കാം).

## എങ്ങനെ ഉപയോഗിക്കാം (3 ഘട്ടങ്ങൾ)

1. നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഹോസ്റ്റ് ചെയ്ത Breeze തുറക്കുക (അല്ലെങ്കിൽ അത് ഹോസ്റ്റ് ചെയ്ത ഒരാൾ നിങ്ങൾക്ക് തന്ന വിലാസം), നിങ്ങളുടെ പേര് നൽകുക. അത്രമാത്രം — നിങ്ങൾ തയ്യാറാണ് (രജിസ്ട്രേഷനില്ല, ഫോൺ നമ്പറില്ല). ഈ സമയത്ത്, നിങ്ങളുടെ ഉപകരണത്തിനുള്ളിൽ ഒരു "കീ" സൃഷ്ടിക്കപ്പെടുന്നു, ആ കീ നിങ്ങളുടെ ഐഡന്റിറ്റിയായി മാറുന്നു.
2. നിങ്ങൾ സംസാരിക്കാൻ ആഗ്രഹിക്കുന്ന വ്യക്തിക്ക് നിങ്ങളുടെ ID അല്ലെങ്കിൽ QR കോഡ് നൽകുക.
3. മറ്റേ വ്യക്തിക്കും ആപ്പ് തുറന്നിട്ടുണ്ടെങ്കിൽ, നിങ്ങൾക്ക് നേരിട്ട് ബന്ധിപ്പിച്ച് സംസാരിക്കാം. അവർക്ക് അത് തുറന്നിട്ടില്ലാത്തപ്പോൾ, നിങ്ങളുടെ സന്ദേശം എൻക്രിപ്റ്റ് ചെയ്ത രൂപത്തിൽ ഒരു "മെയിൽബോക്സിൽ" വയ്ക്കുകയും അവർ അത് തുറക്കുമ്പോൾ എത്തിക്കുകയും ചെയ്യുന്നു. മെയിൽബോക്സ് കൊണ്ടുപോകുന്ന സെർവറിന് ഉള്ളടക്കം വായിക്കാൻ കഴിയില്ല. ഒരിക്കലും എത്താത്ത കത്തുകൾ പരമാവധി 7 ദിവസത്തിന് ശേഷം സ്വയം ഇല്ലാതാകും.

## വാഗ്ദാനങ്ങൾ (ഞങ്ങൾ ചെയ്യാത്തവ)

- **പരസ്യങ്ങളില്ല.** ആപ്പിൽ എവിടെയും ഇല്ല, എവിടെയും ഇല്ല.
- **ട്രാക്കിംഗില്ല.** ഉപയോഗ വിശകലനമില്ല, പരസ്യ സംവിധാനമില്ല, ഡാറ്റ വിൽപ്പനയില്ല.
- **സ്രഷ്ടാവിന്റെ പക്കൽ ഉപയോക്താക്കളുടെ ഡാറ്റയൊന്നുമില്ല.** സെർവർ ഭാഗത്ത് അക്കൗണ്ടുകളുടെ പട്ടിക തന്നെയില്ല. നിങ്ങളുടെ ഐഡന്റിറ്റി എന്നത് നിങ്ങളുടെ ഉപകരണത്തിനുള്ളിലെ കീ മാത്രമാണ്.
- **സംഭാഷണങ്ങൾ ഉപകരണങ്ങൾക്കിടയിൽ എൻക്രിപ്റ്റ് ചെയ്തിരിക്കുന്നു.** സെർവർ കൈകാര്യം ചെയ്യുന്നത് അതിന് വായിക്കാൻ കഴിയാത്ത കവറുകൾ മാത്രമാണ്.

പരിധിയും ഞങ്ങൾ സത്യസന്ധമായി എഴുതുന്നു. ഡെലിവറിക്കായി, സെർവറിൽ ഹ്രസ്വകാല തടഞ്ഞുവയ്ക്കൽ ഉണ്ട് (എത്താത്ത കവറുകൾ പരമാവധി 7 ദിവസം, കണക്ഷൻ സിഗ്നലുകൾ 5 മിനിറ്റ്, വിലാസവും ഉപകരണ രേഖകളും 90 ദിവസം, ഗ്രൂപ്പ് വിവരങ്ങളും അറിയിപ്പ് സബ്‌സ്‌ക്രിപ്‌ഷനുകളും 30 ദിവസം സൂക്ഷിക്കുന്നു. ഇവയെല്ലാം സ്വയം ഇല്ലാതാകുന്നു, ഉള്ളടക്കം വായിക്കാൻ കഴിയില്ല). ക്ലൗഡ് ബാക്കപ്പ് സ്ഥിരമായി ഓഫാണ്. നിങ്ങൾ ഇത് നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഹോസ്റ്റ് ചെയ്താൽ, ആ തടഞ്ഞുവയ്ക്കലും നിങ്ങളുടെ സ്വന്തം നിയന്ത്രണത്തിലാകും.

## നിങ്ങൾക്ക് എന്തൊക്കെ ചെയ്യാം

- ഒറ്റയ്‌ക്കൊറ്റയ്ക്കുള്ള സംഭാഷണങ്ങളും ഗ്രൂപ്പ് സംഭാഷണങ്ങളും (പരമാവധി 1,000 പേർ)
- വോയ്‌സ് കോളുകളും വീഡിയോ കോളുകളും (ഗ്രൂപ്പ് കോളുകൾ പരമാവധി 8 പേർ)
- ഫയലുകൾ അയയ്ക്കൽ (ഒറ്റയ്‌ക്കൊറ്റയ്ക്ക് പരമാവധി 50MB. ഗ്രൂപ്പുകളിലും അയയ്ക്കാം, പക്ഷേ വലുപ്പ പരിധി ചെറുതാണ്)
- ഒന്നിലധികം ഉപകരണങ്ങളും ഒന്നിലധികം അക്കൗണ്ടുകളും ഉപയോഗിക്കൽ (ഉദാ. ജോലിക്കും വ്യക്തിഗത ഉപയോഗത്തിനും. ഉപകരണങ്ങളുടെ എണ്ണവും അക്കൗണ്ടുകളുടെ എണ്ണവും സൗജന്യവും പരിധിയില്ലാത്തതുമാണ്)
- 51 ഭാഷകൾ (ഇംഗ്ലീഷും 50 ഭാഷാ ഫയലുകളും), നിങ്ങളുടെ ഉപകരണത്തിന്റെ ഭാഷയ്ക്ക് അനുസരിച്ച് സ്വയം തിരഞ്ഞെടുക്കപ്പെടുന്നു
- ഫോട്ടോകളുള്ള പ്രൊഫൈലുകൾ, സ്റ്റിക്കറുകൾ, സ്ഥാനം പങ്കിടൽ
- `/help` പോലുള്ള കമാൻഡുകൾ (71 തരങ്ങൾ)
- നിങ്ങളുടെ ബാറ്ററിക്ക് അനുയോജ്യമായ പവർ മോഡുകൾ (സ്വയം / സാധാരണം / വൈദ്യുതി ലാഭിക്കൽ / അടിയന്തരം). ബാറ്ററി കുറയുമ്പോൾ, ബാറ്ററി കൂടുതൽ നേരം നിലനിൽക്കാൻ ഡെലിവറി പരിശോധനകൾ അകലം കൂട്ടുന്നു. ദുരന്തങ്ങൾക്കും റീചാർജ് ചെയ്യാൻ കഴിയാത്ത മറ്റ് സമയങ്ങൾക്കുമുള്ള ഒരു സുരക്ഷാ സംവിധാനം
- വായിക്കാൻ എളുപ്പമുള്ള സ്ക്രീനുകൾ (നിറ വ്യത്യാസം, വാചക വലുപ്പം, കീബോർഡ് കൊണ്ട് മാത്രം പ്രവർത്തിപ്പിക്കൽ എന്നിവയിൽ ശ്രദ്ധ)

| രജിസ്ട്രേഷൻ | ആവശ്യമില്ല (ഐഡന്റിറ്റി എന്നത് നിങ്ങളുടെ ഉപകരണത്തിനുള്ളിലെ ഒരു കീയാണ്) | ഫോൺ നമ്പർ ആവശ്യമാണ് |
| സെർവർ | ഉള്ളടക്കം വായിക്കാൻ കഴിയില്ല | കമ്പനിയെ വിശ്വസിക്കുന്നതിനെ അടിസ്ഥാനമാക്കിയുള്ളത് |
| നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഹോസ്റ്റ് ചെയ്യൽ | മുൻവ്യവസ്ഥ (ഇത് ഹോസ്റ്റ് ചെയ്ത് ഉപയോഗിക്കാനുള്ളതാണ്) | സാധ്യമല്ല |
| സോഴ്‌സ് കോഡ് | എല്ലാം പൊതുവാണ് (MIT ലൈസൻസ്) | പലപ്പോഴും പൊതുവല്ല |
| ഡാറ്റ എവിടെയാണ് | നിങ്ങളുടെ ഉപകരണത്തിനുള്ളിൽ | കമ്പനിയുടെ സെർവറിൽ |

Signal-മായും LINE-മായുമുള്ള വിശദമായ താരതമ്യം [താരതമ്യ പേജിൽ (ഇംഗ്ലീഷ്)](../COMPARISON.md) ഉണ്ട്. Breeze-ന്റെ ഓരോ അവകാശവാദത്തിനും "അത് എങ്ങനെ പരിശോധിക്കാം" എന്നത് നൽകിയിട്ടുണ്ട്, Breeze പരാജയപ്പെടുന്ന കാര്യങ്ങളും (ഉപയോക്താക്കളുടെ എണ്ണം, ബാഹ്യ ഓഡിറ്റ് നടത്തിയിട്ടില്ല എന്നത് മുതലായവ) മറയ്ക്കാതെ എഴുതിയിട്ടുണ്ട്.

## നിങ്ങളുടെ സ്വന്തം സെർവറിൽ ഹോസ്റ്റ് ചെയ്യുന്നതിനുള്ള ചെലവ്

Breeze Cloudflare-ന്റെ സൗജന്യ ടയറിൽ പ്രവർത്തിക്കുന്നു. ക്രെഡിറ്റ് കാർഡ് ആവശ്യമില്ല.

| ഇനം | സൗജന്യ ടയർ | പണമടച്ചത് |
|-----------|-----------|-------------|
| ഹോസ്റ്റിംഗ് | Cloudflare Pages (സൗജന്യം) | — |
| പ്രോസസ്സിംഗ് | ദിവസം 100,000 വരെ | മാസം 10 ദശലക്ഷം വരെ |
| സംഭരണം | ദിവസം 100,000 വായന / 1,000 എഴുത്ത് വരെ | മാസം 10 ദശലക്ഷം വായന / 1 ദശലക്ഷം എഴുത്ത് വരെ |
| കോൾ റിലേ | 20GB വരെ സൗജന്യം | GB-ക്ക് $0.05 |
| ഇഷ്‌ടാനുസൃത ഡൊമെയ്ൻ | ആവശ്യമില്ല (ഒരു സൗജന്യ വിലാസം ഉൾപ്പെടുത്തിയിട്ടുണ്ട്) | വർഷം $10 |
| **ആകെ** | **മാസം $0** (ലഘുവായ ഉപയോഗത്തിൽ ഏകദേശം 20–40 പേർ വരെ) | **മാസം $5 മുതൽ** (ലഘുവായ ഉപയോഗത്തിൽ ഏകദേശം 100 പേർ; 1,000 പേരിൽ, ഉപയോഗത്തെ ആശ്രയിച്ച് മാസം $34–$222) |

വലിയ തോതിൽ ചെലവ് എങ്ങനെ വളരുന്നുവെന്നും, "എന്തുകൊണ്ടാണ് ഒരൊറ്റ ഓപ്പറേറ്റർ എല്ലാവരുടെയും ചെലവ് വഹിക്കേണ്ടതില്ല" എന്നതും [ചെലവും സുസ്ഥിരതയും സംബന്ധിച്ച തത്ത്വചിന്തയിൽ (ഇംഗ്ലീഷ്)](../SUSTAINABILITY.md) ഉണ്ട്, അടിസ്ഥാന കണക്കുകൂട്ടലുകൾ [ചെലവ് മോഡലിൽ (ഇംഗ്ലീഷ്)](../COST_MODEL.md) ഉണ്ട്.

സജ്ജീകരണം ഈ ഒരൊറ്റ കമാൻഡിൽ നിന്ന് ആരംഭിക്കുന്നു (വിശദാംശങ്ങൾക്ക് [സജ്ജീകരണ ഗൈഡ്](SELF_HOSTING-ml.md) കാണുക).

```bash
wrangler pages deploy . --project-name=breeze
```

## സാങ്കേതിക വിശദാംശങ്ങൾ (ഡെവലപ്പർമാർക്കായി)

### എൻക്രിപ്ഷൻ രീതികൾ

| പങ്ക് | രീതി |
|-------|-----------|
| കീ കൈമാറ്റം | X25519 (ബദൽ: P-256) |
| ഒപ്പ് | Ed25519 (ബദൽ: HMAC-SHA256) |
| എൻക്രിപ്ഷൻ | AES-256-GCM |
| കീ വ്യുൽപ്പത്തി | HKDF-SHA256 |
| സംഭാഷണ കീ പുതുക്കൽ | Double Ratchet (Signal ഉപയോഗിക്കുന്ന അതേ രീതി) |
| ഗ്രൂപ്പ് കീകൾ | Sender Key |
| അയച്ചയാളെ റിലേയിൽ നിന്ന് മറയ്ക്കൽ | Sealed Sender |

രൂപകൽപ്പനയുടെ ആധികാരിക രേഖ [സ്പെസിഫിക്കേഷൻ SPEC.md](../../SPEC.md) ആണ്, ബലഹീനതകൾ എവിടെ റിപ്പോർട്ട് ചെയ്യണമെന്നും നയവും [SECURITY.md](../../SECURITY.md) യിൽ ഉണ്ട്.

## English

Breeze is an end-to-end encrypted messenger with no phone number, no registration, and no ads — every feature is free. There is no company server: to use Breeze, you host it on your own server (Cloudflare's free tier is enough) and connect the apps to it. Your identity is a key pair on your device; relays handle only sealed envelopes they cannot read. Full text in English: [docs/i18n/README-en.md](README-en.md). The full, sourced comparison against Signal and LINE — including where Breeze loses — is in [docs/COMPARISON.md](../COMPARISON.md).
