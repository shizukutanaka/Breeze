Breeze သည် ဖုန်းနံပါတ်လည်း မှတ်ပုံတင်ခြင်းလည်း မလိုအပ်သော ကုဒ်ဝှက်ထားသည့် စာတိုပေးပို့ရေးအက်ပ် ဖြစ်ပါသည်။
စကားဝိုင်း၏ အကြောင်းအရာကို ပို့သူနှင့် လက်ခံသူသာ ဖတ်နိုင်ပါသည်။ လမ်းတစ်လျှောက် သယ်ဆောင်ပေးသည့် ဆာဗာပင် မဖတ်နိုင်ပါ။
လုပ်ဆောင်ချက်အားလုံး အခမဲ့ဖြစ်ပြီး ကြော်ငြာလည်း မရှိပါ။

ဤလက်စွဲစာအုပ်သည် စတင်အသုံးပြုသူများအတွက် လမ်းညွှန်တစ်ခု ဖြစ်ပါသည်။

## 1. စတင်နည်း

### ရယူခြင်း

[ဒေါင်းလုဒ်စာမျက်နှာ](https://github.com/shizukutanaka/Breeze/releases/latest) မှ သင့်စက်နှင့် ကိုက်ညီသောအရာတစ်ခုကို ရွေးချယ်ပါ။

- Windows: အမည်သည် `-win-x64.exe` ဖြင့် အဆုံးသတ်သောအရာ (ARM စက်များအတွက်လည်း ရှိပါသည်)
- Mac: အမည်သည် `-mac.dmg` ဖြင့် အဆုံးသတ်သောအရာ
- Linux: `.AppImage` (တိုက်ရိုက် လုပ်ဆောင်နိုင်ပါသည်) သို့မဟုတ် `.deb`
- ဘရောက်ဇာတွင် အသုံးပြုပါက ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသောအရာကို အသုံးပြုရပါသည် (တပ်ဆင်ခြင်း အဆင့်များကို သီးခြားစာရွက်စာတမ်း "တပ်ဆင်ခြင်းလမ်းညွှန်" တွင် ဖော်ပြထားပါသည်)။ ပုံမှန်တပ်ဆင်မှုသည် Cloudflare ကို အသုံးပြုသောကြောင့် Cloudflare အကောင့် လိုအပ်ပါသည်

ဖိုင်တစ်ခုချင်းစီတွင် စစ်ဆေးရန် ဂဏန်းတန်ဖိုး (SHA256SUMS.txt) ပါရှိပါသည်။ စိတ်ပူပါက ဒေါင်းလုဒ်လုပ်ထားသည့် ဖိုင်၏ ဂဏန်းတန်ဖိုး ကိုက်ညီမှု ရှိ၊ မရှိ စစ်ဆေးနိုင်ပါသည်။

> **နမူနာစာမျက်နှာအကြောင်း**: လုပ်ဆောင်ပုံကို စစ်ဆေးရန် နမူနာ (https://breeze-469.pages.dev/) ကို ပေးထားပါသည်။ ထိုနေရာတွင် တင်ထားသည်မှာ တူညီသော ဆော့ဖ်ဝဲပင် ဖြစ်သော်လည်း နမူနာသည် အသိပေးခြင်းမရှိဘဲ ပြောင်းလဲသွားခြင်း သို့မဟုတ် ရပ်တန့်သွားခြင်း ဖြစ်နိုင်ပါသည်။ အမှန်တကယ် အသုံးပြုရန်အတွက် ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသောအရာကို အသုံးပြုပေးပါ။ ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသောအရာသည် နမူနာ ရပ်တန့်သွားပါကလည်း သက်ရောက်မှု မရှိပါ။

### ပထမဆုံး ပြင်ဆင်ခြင်း

1. အက်ပ်ကို ဖွင့်ပါ။
2. "ကျပန်း ID ဖြင့် စတင်ရန်" ကို နှိပ်ပါ။ ထိုမျှဖြင့် ပြင်ဆင်မှု ပြီးဆုံးပါသည်။ မှတ်ပုံတင်ခြင်းလည်း ဖုန်းနံပါတ်လည်း မလိုအပ်ပါ။

- ခလုတ်၏ အထက်ရှိ အကွက်တွင် "သင့်အမည် (ပြသမည့်အမည်)" ကို ထည့်ပါက ထိုအမည်ဖြင့် စတင်ပါမည်။ အကွက်ကို ဗလာထားပြီး ခလုတ်ကို နှိပ်နိုင်ပါသည်။ ပြသမည့်အမည်ကို နောက်ပိုင်းတွင် ပြင်ဆင်သတ်မှတ်မှုများ၏ ပရိုဖိုင် အပိုင်းတွင် ပြောင်းနိုင်ပါသည်။
- သင်ကိုယ်တိုင် ရွေးချယ်သော အမည်နှင့် Breeze ID ဖြင့် အမှတ်အသား ဖန်တီးနည်း လည်း ရှိပါသည်။ ထိုအခါတွင် ပြန်လည်ရယူရေး စကားစုကို ထုတ်ပေးပြီး မျက်နှာပြင်တွင် ပြသပါမည်။ ပြန်လည်ရယူရေး စကားစုသည် ထိုအမှတ်အသားကို အခြားစက်ပစ္စည်းတွင် ပြန်လည်ရယူနိုင်စေသည့် စကားလုံးများ ဖြစ်ပါသည်။ စာရွက်ပေါ်တွင် သို့မဟုတ် လုံခြုံသောနေရာတွင် ရေးမှတ်ထားပါ။
- ယခင်က ဖန်တီးခဲ့သည့် အမှတ်အသားကို ပြန်လည်ရယူလိုပါက "ရှိပြီးသား အကောင့်ကို ပြန်လည်ရယူရန်" ကို ဖွင့်ပါက ပြန်လည်ရယူနည်းများ (အရန်ကူးဖိုင်မှ ပြန်ယူရန်၊ ပြန်လည်ရယူရေး စကားစုဖြင့် ပြန်ယူရန်၊ အကောင့် + လျှို့ဝှက်စကားစုဖြင့် ပြန်ယူရန်) ထွက်လာပါမည်။
- ဖန်တီးမှု ပြီးဆုံးပါက သင့်သော့ကို စကားဝှက်ဖြင့် ကာကွယ်ရန် လမ်းညွှန်သည့် ကတ်တစ်ခု ထွက်လာပါမည် (အချိန်ကြာပြီးနောက် ပျောက်သွားခြင်း မရှိပါ)။ အရေးကြီးသော အမှတ်အသားအတွက် လမ်းညွှန်ချက်အတိုင်း လိုက်၍ ကာကွယ်မှုကို ထည့်ပါ။

ထိုအချိန်တွင် စက်ပစ္စည်းအတွင်း၌ "သော့" တစ်ခု ဖန်တီးပါသည်။ ၎င်းသည် သင်၏ အမှတ်အသား ကိုယ်နှိုက်ပင် ဖြစ်ပါသည်။
**အကောင့်စာရင်းသည် ဆာဗာတွင် မရှိပါ။** အမှတ်အသားသည် သင့်စက်ပစ္စည်းအတွင်း၌သာ ရှိပါသည်။
ဤအချက်သည် အရန်သိမ်းဆည်းခြင်း အခန်း (၉) တွင် အရေးကြီးလာပါမည်။

### ယခင် "တစ်ခါသုံး အမှတ်အသား" အကြောင်း

"တစ်ခါသုံး အမှတ်အသား" — ပြန်လည်ရယူရန် နည်းလမ်း လုံးဝမရှိသည့် အမှတ်အသား — မရှိတော့ပါ။ လက်ရှိ အမှတ်အသား ဖန်တီးနည်းများဖြင့် အမှတ်အသားတိုင်းကို အရန်သိမ်းဆည်းမှုဖြင့် ကာကွယ်နိုင်ပါသည်။

## 2. တစ်ဖက်လူနှင့် ချိတ်ဆက်ခြင်း

အဆက်အသွယ်များ မျက်နှာပြင်ရှိ "သူငယ်ချင်း ထည့်ရန်" ခလုတ်ကို နှိပ်ပါက ရွေးချယ်စရာ ၃ ခု ထွက်လာပါမည်။

- **အဆက်အသွယ် ထည့်ရန်**: တစ်ဖက်လူ၏ ID ကို ထည့်ပါ သို့မဟုတ် QR ကုဒ်ကို စကင်န်ဖတ်ပါ။
- **သူငယ်ချင်းကို ဖိတ်ခေါ်ရန်**: ဖိတ်ခေါ်လင့်ခ်ကို ကူးယူပြီး ပုံမှန် ဆက်သွယ်ရေးနည်းလမ်း (အီးမေးလ် စသည်) ဖြင့် ပို့ပါ။ တစ်ဖက်လူက လင့်ခ်ကို ဖွင့်ပြီး အမည်ထည့်လိုက်သည်နှင့် ချက်ချင်း စကားပြောနိုင်ပါပြီ။
- **အုပ်စု ဖန်တီးရန်**: အုပ်စုအမည်ကို ထည့်လိုက်ရုံဖြင့် ဖန်တီးနိုင်ပါသည် (အခန်း ၄)။

သင်၏ ID ကို သင့်ပရိုဖိုင်ကို ဖွင့်သည့်အခါ အပြည့်အစုံ ပုံစံဖြင့် ပြသထားပြီး ၎င်းအတိုင်း ကူးယူနိုင်ပါသည်။ ID အတိုသာမက ID အပြည့်အစုံကို ပေးနိုင်ပါသည်။

တစ်ဖက်လူလည်း အက်ပ်ကို ဖွင့်ထားပါက တိုက်ရိုက်ချိတ်ဆက်၍ စကားပြောနိုင်ပါသည်။

## 3. စကားဝိုင်း

- စာရိုက်ထည့်ပြီး ပို့လိုက်ရုံသာ ဖြစ်ပါသည်။ ဓာတ်ပုံများ၊ စတစ်ကာများ၊ တည်နေရာ အချက်အလက်များလည်း ပို့နိုင်ပါသည်။
- ထည့်သွင်းရန် အကွက်၏ ဘေးရှိ "+" ကို ဖွင့်ပါက ဖိုင် ပူးတွဲမှုများ၊ အသံစာများ၊ အသံဖြင့် ထည့်သွင်းခြင်း၊ တည်နေရာ အချက်အလက်များ၊ စတစ်ကာများ၊ "အကြောင်းပြန်ရန် မလိုပါ" ပြင်ဆင်သတ်မှတ်ချက်နှင့် အခြားအရာများ အတူတကွ ထွက်လာပါမည်။
- **ဖိုင်ပို့ခြင်း**: တစ်ဦးချင်း စကားဝိုင်းတွင် အများဆုံး 50MB အထိ။ အုပ်စုတွင် ပိုသေးပြီး 50KB ခန့် ဖြစ်ပါသည်။
- လုပ်ဆောင်နိုင်သည့် ဖိုင် စသည့် အန္တရာယ်ရှိသော ပုံစံရှိသည့် ဖိုင်များသည် အလိုအလျောက် ပိတ်ဆို့ခံရပါသည်။
- တစ်ဖက်လူ အက်ပ်ကို မဖွင့်ထားသည့်အခါ စာကို ကုဒ်ဝှက်ထားသည့် အခြေအနေဖြင့် "သိမ်းဆည်းပုံး" တွင် ထားပြီး တစ်ဖက်လူ ဖွင့်သည့်အခါ ပို့ပေးပါသည်။ သိမ်းဆည်းပုံးကို သယ်ဆောင်သည့် ဆာဗာသည် အကြောင်းအရာကို မဖတ်နိုင်ပါ။ မပို့နိုင်ဘဲ ကျန်နေသည့် စာများသည် **အများဆုံး ၇ ရက်** အတွင်း အလိုအလျောက် ပျက်သွားပါသည်။
- စကားဝိုင်း မှတ်တမ်းများကို ဖိုင်သို့ ထုတ်ယူနိုင်သည် သို့မဟုတ် ထည့်သွင်းနိုင်ပါသည်။

### မျက်နှာပြင်ကို ဖတ်နည်း

- **ပို့ဆောင်မှု အခြေအနေ**: စာ၏ ဘေးရှိ အမှတ်အသားဖြင့် သိနိုင်ပါသည်။ ✓ ဆိုသည်မှာ ပို့ပြီးပြီ၊ စက်ဝိုင်းအတွင်းရှိ ✓ ဆိုသည်မှာ သိမ်းဆည်းပုံးတွင် အပ်နှံထားပြီ၊ ✓✓ ဆိုသည်မှာ တစ်ဖက်လူထံ ရောက်ရှိပြီ၊ ဖတ်ပြီးပြီ ဆိုသည်မှာ အပြာရောင် အမှတ်အသား၊ မအောင်မြင်ခြင်း ဆိုသည်မှာ အနီရောင် အမှတ်အသား ဖြစ်ပါသည်။ အရောင်သာမက ပုံသဏ္ဍာန်ဖြင့်ပါ ခွဲခြားထားပါသည်။
- **အဆက်အသွယ် စာရင်း**: နောက်ဆုံး စကားပြောခဲ့သည့် အချိန်ကို ယနေ့အတွက် အချိန်၊ မနေ့ကအတွက် "မနေ့က"၊ ယခုနှစ်အတွက် လ/ရက်၊ ထို့ထက် စောသောအရာအတွက် နှစ်/လ/ရက် အဖြစ် ပြသပါသည်။ မဖတ်ရသေးသည့် စာများ ရှိသော အဆက်အသွယ်များတွင် အမည်နှင့် အချိန်ကို ထင်ရှားစွာ ပြသပါသည်။
- **အဆက်အသွယ်များအတွက် အမည်များ**: "အဆက်အသွယ် အချက်အလက်" ကို ဖွင့်ပါ (အဆက်အသွယ်တစ်ခု၏ ညာဘက်ကလစ် မီနူးတွင် သို့မဟုတ် စကားဝိုင်း၏ "⋮" မီနူးတွင်)၊ ထိုအခါ ထိုအဆက်အသွယ်အတွက် သင့်ကိုယ်ပိုင် အမည် (အမည်ပြောင်) ကို သတ်မှတ်နိုင်ပါသည်။ အမည်ပြောင်များကို ဤစက်ပစ္စည်းပေါ်တွင်သာ သိမ်းဆည်းပြီး အဆက်အသွယ် သို့မဟုတ် အစားထိုးပို့ဆောင်သည့် ဆာဗာသို့ ဘယ်သောအခါမှ မပို့ပါ။ အမည်ပြောင် သတ်မှတ်ပါက ထိုအဆက်အသွယ်က သူတို့ကိုယ်တိုင်အတွက် သတ်မှတ်ထားသော အမည်ကိုလည်း ၎င်း၏ ဘေးတွင် မှိန်သောအရောင်ဖြင့် ပြသပါသည်။ ထိုဒုတိယ အမည်ကို ပြင်ဆင်သတ်မှတ်မှုများ၏ "ကိုယ်ရေးကိုယ်တာ" အပိုင်းရှိ "အဆက်အသွယ်တစ်ခုချင်းစီက သူတို့ကိုယ်တိုင်အတွက် သတ်မှတ်ထားသော အမည်ကိုလည်း ပြပါ" ဖြင့် ပိတ်နိုင်ပါသည်။
- **သင်၏ ကတ်**: စာရင်း၏ ထိပ်ဆုံးတွင် သင့်ပရိုဖိုင် ကတ် ရှိပြီး ၎င်းကို နှိပ်၍ သင့်ပရိုဖိုင်ကို ဖွင့်နိုင်ပါသည်။ စာရင်းနှင့်အတူ ရွေ့လျားပါသည်။
- **ဖုန်းတွင် အောက်ခြေ တက်ဘ်များ**: ဖုန်း အကျယ်တွင် "အဆက်အသွယ်များ" နှင့် "ပြင်ဆင်သတ်မှတ်မှုများ" တက်ဘ်များ မျက်နှာပြင် အောက်ခြေတွင် ထွက်လာပါမည်။
- **စကားဝိုင်း ခေါင်းစီး**: ရှာဖွေရေး သင်္ကေတမှ စကားဝိုင်းအတွင်း ရှာဖွေနိုင်ပါသည်။ "⋮" မီနူးမှ လုံခြုံရေး နံပါတ် စစ်ဆေးခြင်း၊ အကြောင်းကြားချက် ပိတ်ခြင်း၊ ပင်ထိုးခြင်း၊ မဲပေးမှု ဖန်တီးခြင်းနှင့် အခြားအရာများ လုပ်နိုင်ပါသည်။

### အမိန့်များ

ထည့်သွင်းရန် အကွက်တွင် `/` ဟု ထည့်ပါက အမိန့် အကြံပြုချက်များ ထွက်လာပါမည်။ အသုံးပြုနိုင်သည့် အမိန့်များ၏ စာရင်းကို ကြည့်ရန် `/help` ဟု ထည့်ပါ (အမျိုးအစား ၇၁ မျိုး)။
ပြင်ဆင်သတ်မှတ်ခြင်းနှင့် စက်ပစ္စည်း ချိတ်ဆက်ခြင်း စသည့် လုပ်ဆောင်မှုအချို့ကို အမိန့်များမှ လုပ်ဆောင်ရပါသည်။

## 4. အုပ်စု

- အုပ်စုတွင် အများဆုံး **လူ ၁,၀၀၀** အထိ ဝင်နိုင်ပါသည်။
- ဖန်တီးရန် "သူငယ်ချင်း ထည့်ရန်" ရှိ "အုပ်စု ဖန်တီးရန်" အောက်တွင် အုပ်စုအမည်ကို ထည့်လိုက်ရုံသာ ဖြစ်ပါသည် (`/newgroup` အမိန့်ဖြင့်လည်း ဖန်တီးနိုင်ပါသည်)။ ဖိတ်ခေါ်ခြင်းကို "အုပ်စု ဖိတ်ခေါ်လင့်ခ်" မှ လုပ်ဆောင်ပါသည်။ လင့်ခ်ကို လက်ခံရရှိသူသည် အမည်ထည့်၍ ပါဝင်နိုင်ပါသည်။
- အုပ်စုတွင်လည်း ဖိုင်ပို့နိုင်သော်လည်း အကန့်အသတ်မှာ 50KB ခန့်နှင့် သေးငယ်ပါသည်။ အသံစာများကို အုပ်စုတွင် မပို့နိုင်သေးပါ။
- အက်ပ်၏ ဗားရှင်းအဟောင်းကို အသုံးပြုနေသည့် အဖွဲ့ဝင်ရှိပါက ထိုအုပ်စုတွင် ပိုမိုလုံခြုံသည့် နည်းလမ်းအသစ် (အုပ်စု v5) ကို အသုံးမပြုနိုင်ဘဲ မျက်နှာပြင်တွင် သတိပေးချက် ထွက်လာပါမည်။ အားလုံး နောက်ဆုံးဗားရှင်းသို့ အပ်ဒိတ်လုပ်ပါက အသက်ဝင်လာပါမည်။

## 5. ခေါ်ဆိုမှုများ

- တစ်ဦးချင်း အသံခေါ်ဆိုမှုနှင့် ဗီဒီယိုခေါ်ဆိုမှု လုပ်နိုင်ပါသည်။ အုပ်စုခေါ်ဆိုမှုလည်း ရှိပါသည် (အများဆုံး လူ ၈ ဦး)။
- **ခေါ်ဆိုမှု အတည်ပြုကုဒ်**: ခေါ်ဆိုမှု မျက်နှာပြင်တွင် အတည်ပြုကုဒ် ပြသထားပါသည်။ တစ်ဖက်လူနှင့် အပြန်အလှန် ဖတ်ပြပြီး မျက်နှာပြင် နှစ်ဖက်စလုံးတွင် ကိုက်ညီမှု ရှိ၊ မရှိ စစ်ဆေးပါ။ မကိုက်ညီပါက တစ်စုံတစ်ယောက်က လမ်းတစ်လျှောက် နားထောင်နေခြင်း ဖြစ်နိုင်ပါသည်။ ထိုအခါတွင် ခေါ်ဆိုမှုကို ဖြတ်လိုက်ပါ။
- အုပ်စုခေါ်ဆိုမှုသည် အားလုံး၏ အက်ပ်သည် နောက်ဆုံးဗားရှင်း မဟုတ်ပါက စတင်၍ မရနိုင်သည့် အခြေအနေ ဖြစ်နိုင်ပါသည်။

## 6. စက်ပစ္စည်းများစွာနှင့် အကောင့်များစွာ

- စက်ပစ္စည်းများစွာတွင် တူညီသော အမှတ်အသားကို အသုံးပြုရန် `/link` အမိန့်ဖြင့် စက်ပစ္စည်းအချင်းချင်း ချိတ်ဆက်ပါ။
- အကောင့်များကို အများအပြား ဖန်တီး၍ ခွဲခြားအသုံးပြုနိုင်ပါသည် (အလုပ်သုံးနှင့် ကိုယ်ရေးကိုယ်တာသုံး စသဖြင့်)။ စက်ပစ္စည်း အရေအတွက်ရော အကောင့် အရေအတွက်ပါ အခမဲ့နှင့် အကန့်အသတ်မရှိပါ။
- **အကောင့် ဖန်တီးနည်း**: အဆက်အသွယ် စာရင်း၏ အထိပ်ဆုံးရှိ အကောင့် တက်ဘ်များ၏ ဘေးရှိ "+" ခလုတ်ကို နှိပ်ပါ။ အမည်ထည့်ပြီး သင်္ကေတ အီမိုဂျီကို ရွေးချယ်ပါက အကောင့်အသစ် ဖန်တီးပြီး ၎င်းသို့ အလိုအလျောက် ပြောင်းသွားပါမည်။
- **အကောင့် ပြောင်းနည်း**: အကောင့် တက်ဘ်များကို အဆက်အသွယ် စာရင်း၏ အထိပ်ဆုံးတွင် အမြဲ ပြသထားပါသည်။ တစ်ခုကို နှိပ်၍ ပြောင်းနိုင်ပါသည် (ကွန်ပျူတာတွင် Ctrl+1–9 ဖြင့်လည်း ပြောင်းနိုင်ပါသည်)။ တက်ဘ်ကို ဖိနှိပ်ထားပါက အမည် ပြောင်းခြင်း၊ သင်္ကေတ ပြောင်းခြင်း သို့မဟုတ် ဖျက်ခြင်း လုပ်နိုင်ပါသည်။
- အဆက်အသွယ်များနှင့် သော့များသည် အကောင့်တစ်ခုချင်းစီအတွက် သီးခြား ဖြစ်ပါသည်။ အကောင့်တစ်ခုချင်းစီအတွက် အဆက်အသွယ်များကို ထပ်မံ ဖလှယ်ပါ။
- ဘာသာစကားကို အင်္ဂလိပ် အပါအဝင် ဘာသာစကား ၅၁ မျိုးမှ သင့်စက်၏ ဘာသာစကားနှင့် ကိုက်ညီအောင် အလိုအလျောက် ရွေးချယ်ပေးပါသည်။

## 7. လုံခြုံမှု ထိန်းသိမ်းရန် ပြင်ဆင်သတ်မှတ်မှုများ

ပြင်ဆင်သတ်မှတ်မှုများသည် သီးခြား မျက်နှာပြင်တစ်ခုအဖြစ် ပွင့်လာပါသည်။ ဖုန်းတွင် မျက်နှာပြင် အောက်ခြေရှိ "ပြင်ဆင်သတ်မှတ်မှုများ" တက်ဘ်မှ ဖွင့်ပါ၊ ကွန်ပျူတာတွင် မျက်နှာပြင်ရှိ ဂီယာ ခလုတ်မှ ဖွင့်ပါ (`/settings` အမိန့်ဖြင့်လည်း ဖွင့်နိုင်ပါသည်)။ ယခင် မျက်နှာပြင်သို့ ပြန်သွားရန် နောက်ပြန်သွားခြင်း လုပ်ဆောင်ချက်ကို အသုံးပြုပါ။

- **အလိုအလျောက် သော့ခတ်ခြင်း**: တက်ဘ်ကို ပြောင်းသည့်အခါ အလိုအလျောက် သော့ခတ်သည့် ပြင်ဆင်သတ်မှတ်မှု ရှိပါသည်။
- **သော့ စကားဝှက်**: စက်ပစ္စည်းအတွင်းရှိ သော့ကို စကားဝှက်ဖြင့် ရစ်ပတ်၍ ကာကွယ်နိုင်ပါသည်။ အက်ပ်ကို ဖွင့်သည့်အခါ ထည့်သွင်းရန် တောင်းဆိုပါမည်။
- **အဆက်အသွယ်တစ်ခုချင်းစီက သူတို့ကိုယ်တိုင်အတွက် သတ်မှတ်ထားသော အမည်ကိုလည်း ပြပါ**: "ကိုယ်ရေးကိုယ်တာ" အပိုင်းတွင် ဖြစ်ပါသည်။ သင် အမည်ပြောင် ပေးထားသည့် အဆက်အသွယ်အတွက် သူတို့၏ ကိုယ်ပိုင်အမည်ကို ၎င်း၏ ဘေးတွင် ပြသမည် မပြသမည်ကို ရွေးချယ်နိုင်ပါသည် (အခန်း ၃)။
- **ပိတ်ဆို့ခြင်း**: အနှောင့်အယှက်ပေးသည့် တစ်ဖက်လူကို ပိတ်ဆို့နိုင်ပါသည်။ ပိတ်ဆို့ထားသည့် တစ်ဖက်လူထံမှ ဆက်သွယ်မှုများ မရောက်လာပါ။

## 8. ဘက်ထရီနှင့် အရေးပေါ်အခြေအနေ (ပါဝါမုဒ်များ)

"ပါဝါမုဒ်" ပြင်ဆင်သတ်မှတ်မှုတွင် ဘက်ထရီကို မည်သို့ အသုံးပြုမည်ကို ရွေးချယ်နိုင်ပါသည်။

- **အလိုအလျောက် (ဘက်ထရီ ပမာဏ)**: ကျန်ရှိသည့် ဘက်ထရီ ပမာဏအလိုက် အလိုအလျောက် ပြောင်းလဲပါသည်။
- **ပုံမှန်**: ပုံမှန်အတိုင်း ဖြစ်ပါသည်။
- **ပါဝါချွေတာခြင်း**: ပို့ဆောင်မှု စစ်ဆေးခြင်းကို အများဆုံး စက္ကန့် ၆၀ လျှင် တစ်ကြိမ်အထိ အချိန်ခြားပြီး ရှိနေမှု အချက်ပြမှုကို ရပ်တန့်ပါသည်။
- **အရေးပေါ် (ဘေးအန္တရာယ်အတွက်)**: ပို့ဆောင်မှု စစ်ဆေးခြင်းကို အများဆုံး မိနစ် ၁၀ လျှင် တစ်ကြိမ်အထိ အချိန်ခြားပါသည်။ ဘေးအန္တရာယ် ကျရောက်ချိန် သို့မဟုတ် အားပြန်သွင်း၍ မရသော အချိန်တွင် အသုံးပြုပါ။

ဘက်ထရီကို ကုန်ဆုံးစေသည်မှာ ဆက်သွယ်မှု ပမာဏ မဟုတ်ဘဲ ရေဒီယို နိုးထသည့် အကြိမ်ရေသာ ဖြစ်ပါသည်။ ထို့ကြောင့် ပို့ဆောင်သည့် ဘက်ကို အချိန်မခြားဘဲ နားထောင်သည့် ဘက်ကိုသာ အချိန်ခြားပါသည်။ ပို့ဆောင်မှုသည် ပုံမှန်အတိုင်း ချက်ချင်း ထွက်သွားပါသည်။ အားသွင်းခြင်း စတင်ပါက ပိုမိုပေါ့ပါးသည့် ဘက်သို့ တစ်ဆင့် အလိုအလျောက် ပြန်သွားပါသည်။

ဘက်ထရီ ပမာဏကို အလိုအလျောက် မဖတ်နိုင်သည့် စက်ပစ္စည်းများ (iPhone ဘရောက်ဇာ စသည်) တွင် "အလိုအလျောက်" သည် ပုံမှန်အတိုင်း လုပ်ဆောင်ပြီး လက်ဖြင့် ရွေးချယ်မှုသည် ရွေးချယ်ထားသည့်အတိုင်း လုပ်ဆောင်ပါသည်။

## 9. အရန်သိမ်းဆည်းခြင်းနှင့် ပြန်လည်ရယူခြင်း (အရေးအကြီးဆုံး အခန်း ဖြစ်ပါသည်)

Breeze ၏ အမှတ်အသားမှာ သင့်စက်ပစ္စည်းအတွင်းရှိ သော့တစ်ခုသာ ဖြစ်ပါသည်။ အကောင့်စာရင်းသည် ဆာဗာတွင် မရှိဘဲ ဖန်တီးသူ၌လည်း သင်၏ သော့ မရှိပါ။
**စက်ပစ္စည်းကို ပျောက်ဆုံးပါက အမှတ်အသားလည်း ပျောက်ဆုံးသွားပါမည်။** အရေးကြီးသော အမှတ်အသားအတွက် အရန်သိမ်းဆည်းမှုကို သေချာပေါက် ပြုလုပ်ပါ။

အရန်သိမ်းဆည်းခြင်းနှင့် ပြန်လည်ရယူခြင်းကို ပြင်ဆင်သတ်မှတ်မှုများ၏ "အရန်သိမ်းဆည်းခြင်းနှင့် ပြန်လည်ရယူခြင်း" အပိုင်းမှ လုပ်ဆောင်ပါသည် (ခလုတ်များမှာ "အရန်ကူး ဖန်တီးရန်"၊ "အရန်ကူး ပြန်ယူရန်" နှင့် "ဖိုင်မှ ပြန်ယူရန်" ဖြစ်ပါသည်)။ အဆက်အသွယ်ကို ပထမဆုံး အကြိမ် ထည့်သည့်အခါ အရန်သိမ်းဆည်းမှု ပြုလုပ်ရန် တိုက်တွန်းသည့် ကတ်တစ်ခု တစ်ကြိမ်သာ ထွက်လာပါမည်။

### အလိုအလျောက် အရန်သိမ်းခြင်း

"အလိုအလျောက် အရန်သိမ်းခြင်း" ပြင်ဆင်သတ်မှတ်မှုသည် အစမှ ဖွင့်ထားပါသည်။ သင့်ဒေတာ ပြောင်းလဲသည့်အခါ ကုဒ်ဝှက်ထားသော အရန်ကူးကို သင် လက်ခံဆောင်ရွက်ထားသည့် အစားထိုးပို့ဆောင်သည့် ဆာဗာသို့ အလိုအလျောက် ပို့ပါသည်။

- ပြောင်းလဲမှုတိုင်းတွင် မပို့ပါ: နောက်ဆုံး ပြောင်းလဲမှုပြီးနောက် စက္ကန့် ၃၀ စောင့်ပြီး အားလုံးကို အတူတကွ ပို့ပါသည်။ ကြိုးပမ်းမှုများကို အနည်းဆုံး ၁၅ မိနစ် ခြားပါသည်။
- သင် အော့ဖ်လိုင်း ဖြစ်နေစဉ် ဘာမှ မပို့ပါ; ပြောင်းလဲမှုများကို ထိန်းထားပြီး ချိတ်ဆက်မှု ပြန်ရသည့်အခါနှင့် အက်ပ်ကို ဖွင့်သည့်အခါ ပို့ပါသည်။
- အလိုအလျောက် ပို့ဆောင်ရန်အတွက် ထိုစက်ပစ္စည်းတွင် အရန်သိမ်းဆည်းမှု စကားဝှက်ကို တစ်ကြိမ် ထည့်ရန် လိုအပ်ပါသည် (လိုအပ်သည့်အခါ ပြင်ဆင်သတ်မှတ်မှု အပိုင်းတွင် "စကားဝှက် ထည့်ရန်" ခလုတ် ထွက်လာပါမည်)။ **စကားဝှက်ကို မသိမ်းဆည်းပါ။** အက်ပ် ဖွင့်ထားစဉ်တွင်သာ မှတ်မိထားပြီး ပိတ်လိုက်သည့်အခါ ပျောက်သွားပါသည်။ ရိုးရှင်းသော ပြန်လည်ရယူမှု အမှတ်အသားအတွက် မှတ်ပုံတင်ချိန် သို့မဟုတ် အပ်ဒိတ်လုပ်ချိန်တွင် စကားဝှက်ကို ထည့်ပြီးသည်နှင့် ချက်ချင်း ပို့ဆောင်မှုသည် ၎င်းအတိုင်း လုပ်ဆောင်ပါသည်။
- အစားထိုးပို့ဆောင်သည့် ဆာဗာက အရန်ကူးများ သိမ်းဆည်းခြင်းကို မပံ့ပိုးပါက အလိုအလျောက် အရန်သိမ်းခြင်း မလုပ်ဆောင်ပါ။ ထိုအကြောင်းကို ပြင်ဆင်သတ်မှတ်မှု အပိုင်းတွင် ပြသပါသည်။
- အခြေအနေ (နောက်ဆုံး အောင်မြင်သော ပို့ဆောင်မှု ဘယ်တုန်းကလဲ၊ ပြောင်းလဲမှုများ စောင့်နေခြင်း ရှိ မရှိ၊ ပို့ဆောင်မှု မအောင်မြင်ခြင်း ရှိ မရှိ) ကို ပြင်ဆင်သတ်မှတ်မှု အပိုင်းတွင် ပြသပါသည်။

### အရန်သိမ်းဆည်းမှု ပြုလုပ်နည်း (လက်ဖြင့်)

1. ပြင်ဆင်သတ်မှတ်မှုများ၏ "အရန်သိမ်းဆည်းခြင်းနှင့် ပြန်လည်ရယူခြင်း" မှ "အရန်ကူး ဖန်တီးရန်" ကို ရွေးချယ်ပါ။
2. အရန်သိမ်းဆည်းမှုအတွက် စကားဝှက်ကို သတ်မှတ်ပါ (အက္ခရာ ၆ လုံးနှင့်အထက်)။
3. သိမ်းဆည်းမည့်နေရာကို ရွေးချယ်ပါ။
   - **ဖိုင်တွင် သိမ်းဆည်းခြင်း**: အရန်သိမ်းဆည်းမှု ဖိုင်ကို သင့်လက်ထဲတွင် သိမ်းထားပါ (အကြံပြုပါသည်)။
   - **အစားထိုးပို့ဆောင်သည့် ဆာဗာတွင် သိမ်းဆည်းခြင်း**: ထို အစားထိုးပို့ဆောင်သူ၏ လည်ပတ်သူက ဖွင့်ထားသည့်အခါတွင်သာ အသုံးပြုနိုင်ပါသည်။ မူလ အစားထိုးပို့ဆောင်မှုတွင် အသုံးမပြုနိုင်ပါ။ သိမ်းဆည်းထားနိုင်သည့် ကာလ ရှိသည့်အတွက် ကာလ မကုန်မီ ပြန်လည်ရယူပါ။

အရန်သိမ်းဆည်းမှု၏ အကြောင်းအရာကို ကုဒ်ဝှက်ထားပါသည်။ သိမ်းဆည်းမည့်နေရာရှိ ဆာဗာက ကိုင်တွယ်သည်မှာ ကုဒ်ဝှက်စာသားသာ ဖြစ်ပါသည်။

### ပြန်လည်ရယူနည်း

စက်ပစ္စည်းအသစ်တွင် အရန်သိမ်းဆည်းမှု ဖိုင် (သို့မဟုတ် အစားထိုးပို့ဆောင်သည့် ဆာဗာပေါ်ရှိ အရန်သိမ်းဆည်းမှု) နှင့် သတ်မှတ်ထားသည့် စကားဝှက်ကို အသုံးပြု၍ ပြန်လည်ရယူပါ။

သင်၏ အမှတ်အသားကို ပြန်လည်ရယူရေး စကားစုဖြင့် ပြန်လည်ရယူပြီးစီးပါက၊ ထိုအမှတ်အသား၏ အရန်ကူး အစားထိုးပို့ဆောင်သည့် ဆာဗာပေါ်တွင် ရှိပါက ၎င်းကို အလိုအလျောက် တွေ့ရှိပြီး "အရန်ကူး တွေ့ရှိပါပြီ" ဖြင့် သင့်ကို မေးပါမည်။ ၎င်းကို ပြန်လည်ရယူပါက ထိုစက်ပစ္စည်းပေါ်ရှိ ဒေတာကို အရန်ကူး၏ အကြောင်းအရာဖြင့် အစားထိုးပါမည်။

### စက်ပစ္စည်းအသစ်သို့ ပြောင်းရွှေ့ခြင်း

ပြင်ဆင်သတ်မှတ်မှုများ၏ "အရန်သိမ်းဆည်းခြင်းနှင့် ပြန်လည်ရယူခြင်း" အပိုင်းရှိ "စက်ပစ္စည်းအသစ်သို့ ပြောင်းရန်" ခလုတ်ကို နှိပ်ပါက အဆင့်များ ပြသပါမည်။

1. သင်၏ လက်ရှိ စက်ပစ္စည်းတွင် အရန်ကူးကို အစားထိုးပို့ဆောင်သည့် ဆာဗာပေါ်တွင် သိမ်းထားပါ (အလိုအလျောက် အရန်သိမ်းခြင်း သို့မဟုတ် "အရန်ကူး ဖန်တီးရန်")။
2. စက်ပစ္စည်းအသစ်တွင် ပထမ မျက်နှာပြင်တွင် ပြန်လည်ရယူနည်းကို ရွေးချယ်ပြီး သင်၏ ပြန်လည်ရယူရေး စကားစု (သို့မဟုတ် သင်၏ အကောင့်အမည်နှင့် လျှို့ဝှက်စကားစု) ကို ထည့်ပါ။
3. သင်၏ အမှတ်အသား ပြန်ရသည့်အခါ ဆာဗာပေါ်ရှိ အရန်ကူးကို အလိုအလျောက် တွေ့ရှိပြီး ပြန်လည်ရယူရန် ကမ်းလှမ်းပါမည်။

ကေဘယ်ကြိုးများ သို့မဟုတ် ဖိုင် လက်ဆင့်ကမ်းမှုများ မလိုအပ်ပါ။

### သတိပြုရန်

- **စကားဝှက်ကို မေ့သွားပါက ပြန်လည်ရယူ၍ မရပါ။** ဖန်တီးသူကလည်း ပြင်၍ မရပါ။ စကားဝှက်ကို အခြားနေရာတစ်ခုတွင် ရေးမှတ်ထားပါ။
- အလိုအလျောက် အရန်သိမ်းခြင်းအတွက် စကားဝှက်ကို ထည့်ခြင်းသည် စက်ပစ္စည်းတစ်ခုချင်းစီတွင် လိုအပ်ပါသည်။ စက်ပစ္စည်းအသစ်တွင် တစ်ကြိမ် ထပ်ထည့်ပါ။
- သင်၏ အမှတ်အသားများ တိုးလာသည့်အခါ သို့မဟုတ် စက်ပစ္စည်း ပြောင်းသည့်အခါ လက်ဖြင့် အရန်သိမ်းဆည်းမှုကို အသစ်ပြန်လုပ်ပါ။

## 10. သိမ်းဆည်းပုံးနှင့် ကုန်ကျစရိတ်ဆိုင်ရာ အတွေးအခေါ်

- တစ်ဖက်လူ အော့ဖ်လိုင်း ဖြစ်နေသည့်အခါ စာများကို အစားထိုးပို့ဆောင်သည့် ဆာဗာ၏ "သိမ်းဆည်းပုံး" တွင် ကုဒ်ဝှက်ထားသည့် အခြေအနေဖြင့် ထားပါသည် (အများဆုံး ၇ ရက်)။
- အစားထိုးပို့ဆောင်မှုတွင် အလွဲသုံးစားမှု ကာကွယ်ရန်အတွက် အကန့်အသတ်များ (သိမ်းဆည်းနိုင်သည့် ပမာဏနှင့် အကြိမ်ရေ) ရှိပါသည်။ အကန့်အသတ်သို့ ရောက်ပါက ထိုကာလအတွင်း စာအသစ်များ သိမ်းဆည်း၍ မရတော့သော်လည်း **ရောက်ရှိပြီးသား စာများ ပျောက်သွားခြင်း မရှိပါ**။ မျက်နှာပြင်တွင် အကြောင်းရင်းနှင့် စောင့်ရမည့် အချိန်ကို ပြသပါသည်။
- အကန့်အသတ်များကို ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ပါက ကိုယ်တိုင် သတ်မှတ်နိုင်ပါသည်။

ဆာဗာဘက်တွင် ကျန်ရှိနေသည့် မှတ်တမ်းများ၏ နယ်ပယ် (အားလုံး အလိုအလျောက် ပျက်သွားပြီး အကြောင်းအရာကို မဖတ်နိုင်ပါ):

| အရာ | ကျန်ရှိမည့် ကာလ |
|---|---|
| မပို့ရသေးသည့် စာများ | အများဆုံး ၇ ရက် |
| ချိတ်ဆက်မှု အချက်ပြမှုများ | ၅ မိနစ် |
| လိပ်စာနှင့် စက်ပစ္စည်း မှတ်တမ်းများ | ရက် ၉၀ |
| အုပ်စု အချက်အလက်နှင့် အကြောင်းကြားချက် စာရင်းသွင်းမှုများ | ရက် ၃၀ |

## 11. အပ်ဒိတ်လုပ်နည်း (ဒက်စ်တော့ ဗားရှင်း)

1. ဗားရှင်းအသစ် ရှိပါက မျက်နှာပြင်တွင် အသိပေးချက် ထွက်လာပါမည်။
2. "ဒေါင်းလုဒ်" ကို နှိပ်ပါက ဗားရှင်းအသစ်ကို သွားယူပါမည် (အလိုအလျောက် မထည့်သွင်းပါ)။
3. ဒေါင်းလုဒ် ပြီးဆုံးပါက "ထည့်သွင်းရန်" ကို နှိပ်၍ ပြန်စပါ။

အပ်ဒိတ်လုပ်နေစဉ် မအောင်မြင်ပါက (ဖိုင် စစ်ဆေးမှု မကိုက်ညီခြင်း စသည်) **အပ်ဒိတ်ကို ရပ်တန့်ပြီး အကြောင်းရင်းကို မျက်နှာပြင်တွင် ပြသပါမည်**။ ဗားရှင်းအဟောင်းသို့ ပြန်သွားခြင်း မလုပ်နိုင်ပါ။

## 12. ပြဿနာ ကြုံရသည့်အခါ

| လက္ခဏာ | စစ်ဆေးရမည့်အရာ |
|---|---|
| စာ ပို့၍ မရပါ | စက်ပစ္စည်း၏ အချိန် လွဲနေခြင်း ရှိ၊ မရှိ စစ်ဆေးပါ။ အချိန် လွဲနေပါက ပို့ဆောင်မှု မအောင်မြင်ပါ။ |
| တစ်ဖက်လူထံ မရောက်ပါ | တစ်ဖက်လူ အက်ပ်ကို ဖွင့်သည်အထိ သိမ်းဆည်းပုံးတွင် စောင့်နေပါသည် (အများဆုံး ၇ ရက်)။ |
| ဖိုင် ပို့၍ မရပါ | အရွယ်အစား အကန့်အသတ် (တစ်ဦးချင်း 50MB၊ အုပ်စု 50KB ခန့်) ထက် ကျော်လွန်နေခြင်း ရှိ၊ မရှိ၊ သို့မဟုတ် အန္တရာယ်ရှိသော ပုံစံအဖြစ် ပိတ်ဆို့ခံရခြင်း ရှိ၊ မရှိ စစ်ဆေးပါ။ |
| ခေါ်ဆိုမှု အတည်ပြုကုဒ် မကိုက်ညီပါ | ခေါ်ဆိုမှုကို ဖြတ်ပြီး ပြန်ခေါ်ပါ။ မကိုက်ညီသည့် အခြေအနေဖြင့် ဆက်မလုပ်ပါနှင့်။ |
| စကားဝှက်ကို မေ့သွားပါသည် | ပြန်လည်ရယူ၍ မရပါ။ အမှတ်အသားအသစ် ဖန်တီးပြီး တစ်ဖက်လူကို ပြန်လည် အသိပေးပါ။ |
| စက်ပစ္စည်း ပျောက်ဆုံးသွားပါသည် | အရန်သိမ်းဆည်းမှု ရှိပါက စက်ပစ္စည်းအသစ်တွင် ပြန်လည်ရယူနိုင်ပါသည်။ မရှိပါက အမှတ်အသားအသစ် ဖြစ်သွားပါမည်။ |
| နမူနာစာမျက်နှာ ဖွင့်၍ မရပါ | နမူနာသည် အသိပေးခြင်းမရှိဘဲ ရပ်တန့်သွားနိုင်ပါသည်။ ကိုယ်ပိုင်ဆာဗာပေါ်တွင် တင်ထားသောအရာကို အသုံးပြုပေးပါ။ |

ချို့ယွင်းချက် တိုင်ကြားမှုများကို [Issue စာမျက်နှာ](https://github.com/shizukutanaka/Breeze/issues) သို့ ပို့ပေးပါ။

## 13. Breeze ၏ ကတိကဝတ်များ

- ကြော်ငြာ မပြပါ။ အက်ပ်အတွင်းမှာရော မည်သည့်နေရာမှာမှ မပြပါ။
- ခြေရာခံ မလုပ်ပါ။ အသုံးပြုမှု ခွဲခြမ်းစိတ်ဖြာခြင်း၊ ကြော်ငြာစနစ်များ၊ ဒေတာ ရောင်းချခြင်း လုံးဝ မလုပ်ပါ။
- ဖန်တီးသူသည် အသုံးပြုသူများ၏ ဒေတာကို မကိုင်ဆောင်ပါ။ ဆာဗာဘက်တွင် အကောင့်စာရင်း ကိုယ်နှိုက်ပင် မရှိပါ။
- စကားဝိုင်းများကို စက်ပစ္စည်းအချင်းချင်းကြား ကုဒ်ဝှက်ပါသည်။ ဆာဗာက ကိုင်တွယ်သည်မှာ မဖတ်နိုင်သည့် စာအိတ်များသာ ဖြစ်ပါသည်။

အခြား စာတိုပေးပို့ရေးအက်ပ်များနှင့် အသေးစိတ် နှိုင်းယှဉ်ချက်ကို ရီပိုစီတိုရီ၏ "နှိုင်းယှဉ်ချက် စာမျက်နှာ" တွင် Breeze ရှုံးနိမ့်နေသည့် အချက်များ (အသုံးပြုသူ အရေအတွက်၊ ပြင်ပ စစ်ဆေးမှု မခံရသေးခြင်း စသည်) အပါအဝင် ရေးသားထားပါသည်။
