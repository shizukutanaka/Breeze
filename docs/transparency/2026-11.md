## Operating status

**The default relay is not currently operating.** The public
demo at breeze.pages.dev returns 404; restoring it is an
owner-side operations task (see `docs/SUSTAINABILITY.md` §4).
Self-hosted copies are unaffected — anyone can run the relay
from this repository today, and several of the numbers below
only become meaningful once a default instance is deployed
again. This report publishes anyway: the procedure's rule is
that a quiet month is reported, not skipped.
